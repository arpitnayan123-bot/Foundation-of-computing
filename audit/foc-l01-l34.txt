What is Computing?

Computing is fundamentally different from computers as devices. Computing is the abstract process of
solving problems through a well-defined series of steps, taking information as input, processing it, and
producing useful results. This concept predates modern electronic computers by centuries.

Historical Examples of Computing:
  • Ancient Abacus (3000 BC): Merchants used this tool to perform addition and subtraction,
    demonstrating that computing existed before electronic machines

  • Navigation Tables (1600s-1800s): Sailors used pre-calculated tables to determine their positions at

  • Human Computers (World War II): Women performed complex arithmetic calculations to determine

These examples illustrate that computing is a methodology, not dependent on any particular technology.


The IPO Model: Foundation of All Computing

The IPO Model (Input-Process-Output) is the fundamental principle underlying every computing process:

  • Input: Raw data or information provided to the system
  • Process: The execution of algorithms and logical operations on the input
  • Output: The meaningful result produced after processing

This model applies universally—from simple calculators to artificial intelligence systems. Understanding
this model is essential because it appears in every digital application and device.


Real-World Examples of the IPO Model

Smartphone Applications:
  • Input: User touches and swipes on the screen (e.g., selecting food items in a delivery app)
  • Process: App logic executes based on user actions (e.g., adding items to cart, processing payments)
  • Output: Visual feedback appears on the screen for each action

YouTube Recommendation Engine:

Computing vs. Computer: A Critical Distinction

Computing is the abstract intellectual concept of problem-solving through defined, step-by-step
procedures. Computer is the physical electronic tool that executes computing processes with speed and
precision.

Key differences:
  • Computing existed for thousands of years before electronic computers were invented
  • Computing can be performed with pen and paper, an abacus, or any computational tool
  • Computers are fast executors of computing processes, but the intelligence and problem-solving
    methodology comes from humans who design the algorithms
  • When asked to define computing, avoid mentioning computers—focus on the process and methodology


The Four Pillars of Computing

All computing processes depend equally on four essential pillars. The failure of any single pillar causes the
entire computing process to fail:

  • Data: Raw, unprocessed facts and observations that serve as the foundation for computing
  • Algorithm: Well-defined set of instructions that process data
  • Hardware: Physical electronic components that execute instructions
  • Software: Programs and code that implement algorithms


Understanding Data: The Foundation of Computing

Data is any raw, unprocessed fact or observation that can be recorded and stored. By itself, isolated data
has no inherent meaning—it requires context to become valuable.

Data vs. Information:
  • A number like "38.5" is raw data with no meaning
  • "Patient's temperature is 38.5 degrees Celsius" provides context and becomes information
  • Raw data requires context to be meaningful and useful

Examples of Data with and without Context:
  • "42" = meaningless raw data
  • "Age = 42" = meaningful information providing context
  • "Mumbai" = just a word
  • "Place of birth = Mumbai" = meaningful information with context

Data in Modern AI Systems:
Data is the lifeblood of artificial intelligence. Advanced models require significantly larger datasets than
traditional machine learning models. Key principles:

  • More advanced models require more training data

  • Data enables systems to learn, adapt, and make predictions
  • Machine learning models use training data to identify patterns
  • Better quality and quantity of training data produces better prediction results
  • Without data, even the most sophisticated algorithms are completely useless


The Data-Information-Knowledge-Wisdom Chain

Data progresses through a hierarchy as it gains meaning and application:

Data → Information → Knowledge → Wisdom

Clinical Example: Patient Temperature Analysis
  • Data: 38.5 (raw number)
  • Information: Patient's temperature is 38.5°C over four days showing an upward trend, peaking on day
    four (context and pattern recognition)
  • Knowledge/Insights: This fever pattern is consistent with viral infection, likely to resolve in 3-5 days
    (analysis and inference based on patterns from similar cases)
  • Wisdom: Doctor prescribes specific treatment based on pattern recognition from thousands of similar
    cases (decision-making and action)

This progression demonstrates how raw data transforms through processing, analysis, and decision-
making into wisdom that drives actions.


Key Takeaways

  • Computing is about solving problems through well-defined steps, not about machines
  • The IPO model (Input-Process-Output) is universal across all computing applications
  • Every application on smartphones, search engines, maps, and AI systems operates on this fundamental
    principle
  • Computing requires four essential pillars: data, algorithm, hardware, and software
  • Data must be contextualized to become meaningful information
  • Understanding computing principles is essential before learning to program

    Lecture 3: Understanding Data: Classification and
    Organization

Overview

Data is classified into various types to determine appropriate processing methods and analysis techniques.
Understanding these classifications is fundamental to computing and data analysis, as each type requires
different handling approaches and operations.


Main Classifications of Data

1. Structured vs. Unstructured vs. Semi-Structured Data

Structured Data
  • Organized into rows (records) and columns (fields) in a tabular format
  • Each field has a defined data type (number, text, date, yes/no)
  • Enables easy searching, sorting, filtering, and analysis operations
  • Examples: CSV files, Excel spreadsheets, Google Sheets, database tables, bank transaction records,
    student marksheets, hospital patient registers, e-commerce order tables
  • Represents a smaller portion of global data

Unstructured Data
  • Does not follow a predefined format or organization
  • Cannot be neatly placed into rows and columns
  • Comprises approximately 80% of all data generated globally
  • Types include:
      ◦ Text: emails, messaging chats, news articles, customer reviews, social media posts
      ◦ Images: photos, medical x-rays, satellite imagery, ID card scans
      ◦ Audio: voice calls, podcasts, music files, voice notes
      ◦ Video: CCTV footage, YouTube videos, recorded lectures
      ◦ Sensor data: raw IoT device readings without labels
  • Processing requires specialized tools and techniques like transformers for natural language processing
    and computer vision for images

Semi-Structured Data
  • Falls between structured and unstructured data
  • Has some organizational markers but not in tabular format
  • Examples: JSON files (used in web APIs), XML files, HTML pages, emails (with fixed headers but free-
    form body)
  • Allows for organization and analysis despite lacking rigid row-and-column structure

2. Data Across Time: Cross-Sectional, Panel, and Time Series Data

Cross-Sectional Data
  • Collected from multiple subjects (people, cities, companies) at a single point in time
  • Captures a snapshot at one moment

  • Allows comparison across subjects but cannot track individual changes over time
  • Examples: election polls, consumer surveys, Amazon product feedback, census data, medical studies
    comparing patient groups
  • Use case: survey of 500 students in Delhi on June 1, 2025

Panel Data (Longitudinal Data)
  • Tracks multiple subjects over multiple time periods in sequence
  • Combines breadth of cross-sectional data with multiple time points
  • Enables both cross-subject comparison and over-time trend analysis
  • More information-rich than cross-sectional or time series data alone
  • Examples: monthly marks of students tracked over six months, NREGA employment records (collected
    yearly), IMF macroeconomic data across countries over years, clinical drug trials, school performance
    tracking
  • Allows analysis of which subject improved most over time

Time Series Data
  • Collected for a single subject at multiple points in time in sequence
  • Focus is on tracking one entity over different time instances
  • Time is the key dimension, and sequence matters
  • Reveals trends, cycles, and sudden changes
  • Examples: daily closing stock prices, weather forecasting data, ECG heartbeat monitoring, website
    traffic, epidemic spread and case counts, smartphone step counter data, electricity meter readings,
    financial market data
  • Note: Distinguished from panel data by tracking only one subject rather than multiple subjects

3. Quantitative vs. Qualitative Data

Quantitative Data (Quant Data)
  • Numerical and measurable
  • Can be counted or measured
  • Two subtypes:
      ◦ Discrete: Countable whole numbers (e.g., number of students: 30, number of goals: 3, number of
        apps: 47)
      ◦ Continuous: Any value within a range including decimals (e.g., height: 172.4 cm, temperature:
        36.8°C, time: 9.5 seconds)
  • Mathematical operations possible: addition, subtraction, mean, median, standard deviation, correlation
  • Advantages: quick and easy to analyze, less prone to errors and biases, enables identification of trends
    and patterns, results can be generalized with representative sampling
  • Collection method: surveys
  • Answers questions like: what, how often, how many, how much

Qualitative Data (Qual Data)
  • Categorical and non-numerical
  • Represents labels, categories, qualities, and opinions
  • Two subtypes:
      ◦ Nominal: Categories with no natural order (e.g., blood group A/B/AB/O, city of birth, phone brand).
        Operations possible: mode, frequency count, chi-square test

      ◦ Ordinal: Categories with meaningful order but unequal gaps (e.g., Amazon star ratings 1-5,
        education level, customer satisfaction: poor/fair/good/excellent)
  • Includes natural language text, feedback, and opinions
  • Advantages: provides in-depth insights and contextual information
  • Collection method: interviews
  • Answers questions like: how, why
  • Limitations: analysis more prone to researcher bias, requires thematic or content analysis,
    interpretation is subjective

4. Primary vs. Secondary Data
  • Primary Data: Collected directly from the source for a specific purpose
  • Secondary Data: Already collected data repurposed for a different analysis


Importance of Data Classification

Understanding data types is crucial for programmers and data analysts because:

  • Type of data determines which operations are meaningful and valid
  • Cannot perform mean or median on nominal or ordinal data
  • Averaging city of birth would yield no meaningful insight
  • Proper classification ensures appropriate analysis methods and reliable conclusions

Why Learn Programming in the Age of AI and LLMs?

The Vibe Coding Phenomenon
Vibe coding—using AI language models like ChatGPT, Gemini, or Claude to generate code through natural
language prompts—is gaining popularity. However, relying solely on vibe coding poses significant
challenges:

  • Debugging Complexity: While code generation is easy, identifying and fixing errors becomes

  • Code Quality Issues:

  • Production Failures: When AI-generated scripts fail in live production environments, developers
    without programming knowledge cannot troubleshoot issues

  • Developers and managers remain legally and financially accountable for code failures, regardless of
    whether code was AI-generated
  • Regulatory bodies (RBI for banking, SEBI for financial markets, IRDAI for insurance) impose heavy
    penalties for code violations
  • Real-world example: PTM faced bans for data security mismanagement in applications

Current Reality of LLM Capabilities
  • LLMs excel at generating simple code and 80% of prototype work
  • LLMs struggle with complex programming, architecture design, and integration with legacy systems

What is Computing?

Definition and Core Concept
Computing is the process of using well-defined logical steps to solve problems by collecting information,
processing it, and producing useful results. It is not dependent on computer technology but rather on the
delegation of repetitive, logical tasks to machines.

Historical Context
  • During World War II, "computers" were women working at desks manually calculating artillery
    trajectories using pencil and paper
  • The core concept remains unchanged: delegating repeatable logical steps to a mechanism to solve
    problems at speeds humans cannot achieve


IPO Model (Input-Process-Output)

The fundamental framework for all computing tasks:

Traditional IPO Model (30 years ago):
  • User provides input via keyboard
  • CPU processes data
  • Output displayed on screen

Enterprise IPO Model (Current Era):
  • Input: High-velocity, high-variety, high-volume data streams
      ◦ Real-time sensor data
      ◦ Structured and unstructured data
      ◦ Multiple data formats (text, audio, video, sensor readings)
      ◦ Data measured in zettabytes (10²¹ bytes)
  • Process: Automated algorithms powered by cloud infrastructure executing logical steps billions of
    times per second, reducing computational costs to near zero
  • Output: Actionable insights and business decisions translated into revenue growth or cost reduction

  • Process: Physics-based and AI computer models analyzing data streams
  • Output: Local weather forecasts for coming days
  • Business Impact: Critical for agriculture, logistics, and disaster management

Overview of the Lecture

This lecture covers the fourth classification of data (primary vs. secondary data and metadata) and
introduces the second pillar of computing: algorithms. The session builds on previous discussions of data

Data Classification: Origin-Based (Fourth Classification)

Primary Data
Primary data is data collected firsthand by researchers for a specific purpose and is original, not previously
published.

Collection Methods:
  • Creating and distributing surveys (e.g., Google Forms via email, WhatsApp, social media)
  • Conducting experiments and recording observations
  • Collecting sensor readings from deployed IoT (Internet of Things) devices
  • Arduino microcontrollers and weather stations collecting physical data

Advantages:
  • Tailored to exact research questions and purposes
  • Reliable source with known collection methods
  • Direct control over data gathering process

Disadvantages:
  • Time-consuming (requires survey creation, distribution, and response collection)
  • Expensive, requiring financial and human resources
  • Often limited to smaller sample sizes due to cost and time constraints

Secondary Data
Secondary data is data collected by someone else for a different purpose, which is then reused for new
analysis.

Sources:
  • Bloomberg and Prolific databases
  • SEBI (Securities and Exchange Board of India) data
  • IRDAI (Insurance Regulatory and Development Authority) data
  • NSSO (National Sample Survey Office) survey data
  • WHO Global Health Statistics
  • Government census data
  • Wikipedia structured data

Advantages:
  • Large-scale data collection possible due to organizational resources

  • Often available for free or at minimal cost
  • Authoritative and controlled by established organizations

  • May not perfectly match specific research questions

Importance:
  • Critical for organizing, finding, and governing large datasets
  • Reveals information without exposing actual content
  • Essential for data management and system organization


Introduction to Algorithms

Definition and Core Concept
An algorithm is the intellectual core of computing—a finite, unambiguous, step-by-step procedure for
solving a well-defined problem. Algorithms exist independently of computers; computers are simply
machines that execute algorithms very rapidly.

Historical Context
  • The term "algorithm" derives from Muhammad Ibn Musa Al-Qarizmi, a 9th-century Persian
    mathematician
  • His work on arithmetic and algebra introduced systematic problem-solving methods
  • The word "algebra" also originates from his book title
  • Algorithms existed before modern computers (e.g., women "computers" calculating artillery trajectories

  • The quality of computing depends on algorithm quality, not just hardware power
  • A well-optimized algorithm can work effectively even with less computing power
  • A bad algorithm produces wrong or slow results regardless of hardware capability
  • Researchers in the 1990s conducted AI research with limited computing power by optimizing

Five Essential Properties of Algorithms

1. Finiteness
  • Algorithm must terminate after a finite number of steps
  • Cannot run forever or loop infinitely
  • Example of bad algorithm: "Divide n by 2 until n equals 0" (will never reach exactly 0)

2. Definiteness (Unambiguity)
  • Every instruction must be precisely and clearly defined with no room for interpretation or subjectivity
  • Same step must produce identical results every time
  • Bad example: "Add a little bit of salt" (subjective)
  • Good example: "Add exactly 5 grams of salt" (precise and objective)

3. Input
  • Algorithm may have zero or more inputs
  • Inputs are values given before or during execution
  • Examples:
      ◦ Finding maximum of two numbers requires 2 inputs
      ◦ Computing factorial requires 1 input (the number)
      ◦ Sorting a list requires the list as input
      ◦ Displaying "Hello World" requires 0 inputs

4. Output
  • Algorithm must produce at least one output (result of computation)
  • Without output, the algorithm is pointless
  • Examples:
      ◦ Maximum algorithm outputs the larger number
      ◦ Factorial algorithm outputs the factorial value
      ◦ Sorting algorithm outputs the sorted list
      ◦ Navigation algorithm outputs step-by-step route

5. Effectiveness
  • Every step must be basic enough to be performed by a person using pen and paper (in principle)
  • No step should require infinite resources or be physically impossible
  • Resource requirements should be optimal and practical
  • Bad examples:
      ◦ Finding the largest prime number (numbers are infinite)
      ◦ Asking 1 billion users simultaneously (requires infinite resources)

Processing Units: The Brain of Computing

CPU (Central Processing Unit)
The general-purpose brain of the computer that executes instructions sequentially at high speed.

Key Components:
  • ALU (Arithmetic Logical Unit): Performs arithmetic operations (addition, subtraction, multiplication,

  • Control Unit (CU): Orchestrates instruction fetching from memory, decoding, and directing operations

Performance Metrics:

GPU (Graphics Processing Unit)
Designed differently from CPUs, optimized for parallel processing of large datasets.

Architecture Differences:

    data points simultaneously

Original Purpose: Graphics rendering and video game pixel color and position calculations

Current Applications in AI:
  • Training neural networks for computer vision and machine vision

Memory: Where Data Resides

Memory stores data currently being used by the computer. Two primary types exist with different
characteristics.

RAM (Random Access Memory) - Fast and Temporary

Characteristics:
  • Volatile: Contents are lost when power is cut
  • Fast: Data accessed in nanoseconds, much faster than storage
  • Limited Storage: Typical phones have 6-12 GB; laptops have 8-32 GB

Function: The computer's working memory, similar to a physical desk while studying

Usage: When apps are opened, they load from storage into RAM for execution. Variables, lists, and objects
exist in RAM during runtime and are cleared when programs close.

ROM (Read-Only Memory) - Permanent and Immutable

Characteristics:
  • Non-volatile: Instructions remain intact even without power
  • Permanent: Instructions burned at factory and cannot be changed
  • Primary Memory: Like RAM, part of the main memory system

Contents:
  • Firmware and bootloader (program running before OS starts)
  • Fixed instructions that ensure system initialization

Secondary Storage - Permanent Data Storage
Where data lives permanently, even when devices are powered off. This is where documents, images,
videos, Python files, music, and databases are kept.

Types of Secondary Storage:
  • SSD (Solid State Drive): Modern replacement for hard disk drives; faster access speeds
  • HDD (Hard Disk Drive): Older technology, now less common
  • Cloud Storage: Internet-based storage on remote servers, accessible via internet
  • USB Drives and SD Cards: Portable storage for data transfer
  • Optical Disks: Older storage media

5. DIKW Model - Data to Wisdom Pyramid
A hierarchical framework showing data transformation:

Data (Base Level):
  • Raw, unprocessed facts and figures
  • Numbers, coordinates, or observations without context
  • Example: "42" or "Mumbai"

Information (Second Level):
  • Data organized with context and structure
  • Answers "who, what, where, when" questions
  • Requires three elements: a question to answer, data processing, and relationship identification
  • Example: "Your age is 42" or "Your place of birth is Mumbai"

Knowledge (Third Level):
  • Accumulation of information over time
  • Pattern recognition and understanding relationships
  • Answers "why" questions
  • Allows confident action on information

Wisdom (Top Level):

    Lecture 11: Introduction to Lists in Python

A list is a collection of items arranged in a particular order. Lists can contain any type of elements, such as
letters, numbers, or names, and the items do not need to be related to each other in any way.


Overview of Lists

Lists are fundamental data structures in Python that allow you to store multiple values in a single variable.
The naming convention for lists typically uses plural forms (e.g., letters , digits , names , motorcycles )
since they contain multiple elements.


Creating and Printing Lists

  • Syntax: Lists are created using square brackets with elements separated by commas
  • Example: bicycles = ['Trek', 'Cannondale', 'Red Line', 'Specialized']
  • Output: Printing a list displays all its elements in the same format they were stored
  • print(bicycles) outputs: ['Trek', 'Cannondale', 'Red Line', 'Specialized']


Accessing Elements in a List

  • Index Positions: Lists are ordered collections where each element has a specific position
      ◦ The first element is at index 0 (not 1)
      ◦ The second element is at index 1
      ◦ The third element is at index 2, and so forth
  • Syntax: Access elements using the list name followed by the index in square brackets
      ◦ bicycles[0] returns 'Trek'
      ◦ bicycles[1] returns 'Cannondale'
  • Formatting Elements: You can apply string methods to accessed elements
      ◦ bicycles[0].title() converts 'trek' to 'Trek'
      ◦ .upper() converts to uppercase; .lower() converts to lowercase


Accessing the Last Element

  • Negative Indexing: Python provides a special syntax for accessing elements from the end of the list
      ◦ bicycles[-1] always returns the last element (in this case, 'Specialized' )
      ◦ bicycles[-2] returns the second-to-last element
      ◦ bicycles[-3] returns the third-to-last element, and so on
  • Benefit: This method is useful when you don't know the list's length or when working with dynamic
    lists


Using Individual List Values

  • String Concatenation: You can combine list values with strings using the concatenation operator ( + )
  • Example: message = 'My first bicycle was a ' + bicycles[0].title() + '.'
  • Output: 'My first bicycle was a Trek.'

This lecture covers various operations for organizing and managing lists in Python, including sorting,

Sorting a List Permanently with the Sort Method

  • The sort() method arranges list elements in alphabetical, numerical, or reverse order permanently
  • Syntax: list_name.sort()
  • Example: A list of car names (BMW, Audi, Toyota, Subaru) can be sorted alphabetically using
     cars.sort() , resulting in (Audi, BMW, Subaru, Toyota)

  • To sort in reverse order, use: cars.sort(reverse=True) , which produces (Toyota, Subaru, BMW, Audi)
  • The sort method permanently changes the list order for the rest of the program


Sorting a List Temporarily with the Sorted Function

  • The sorted() function displays a list in sorted order without permanently changing the original list
  • Syntax: print(sorted(list_name))
  • Example: sorted(cars) displays (Audi, BMW, Subaru, Toyota), but when you print the original list
    again, it remains in its original order (BMW, Audi, Toyota, Subaru)
  • The sorted function accepts the same reverse=True argument for reverse sorting
  • Example: sorted_cars = sorted(cars, reverse=True) stores the reverse-sorted list in a variable
    temporarily


Printing a List in Reverse Order

  • The reverse() method permanently reverses the order of a list
  • Syntax: list_name.reverse()
  • Example: cars.reverse() changes (BMW, Audi, Toyota, Subaru) to (Subaru, Toyota, Audi, BMW)
  • Unlike sorting, reversing simply inverts the order without any alphabetical arrangement
  • The change is permanent, but you can apply reverse() again to restore the original order


Finding the Length of a List

  • The len() function returns the number of items in a list
  • Syntax: len(list_name)
  • Example: A list with four cars has a length of 4
  • Important: Do not confuse length with index position (a list of length 4 has indices 0, 1, 2, and 3)

  • Error message: "list index out of range"
  • Common cause: The "off-by-one" nature of indexing—lists start at index 0, so a list of length 3 has

Overview

Looping Through an Entire List

Introduction to For Loops
  • Purpose: For loops allow iteration through all elements in a list without writing repetitive code
  • Problem Solved: Eliminates the need to write individual print statements for each list element, which
    becomes impractical with large lists
  • Benefit: Code automatically adapts if list length changes

For Loop Syntax

   for [variable_name] in [list_name]:
        [statement to execute]


  • for : keyword indicating loop start
  • variable_name : stores each individual value from the list during each iteration
  • in : keyword connecting variable to list
  • list_name : the list to iterate through
  • : (colon): required syntax element that marks the beginning of the loop body

How For Loops Work
 1. Python takes the first value from the list and stores it in the variable
 2. Executes all indented statements below the for line
 3. Moves to the next value and repeats the process
 4. Loop terminates automatically when all list elements are processed

Multiple Statements in Loops
  • You can include multiple statements within a loop
  • All indented lines following the for statement are executed for each list element
  • Non-indented lines after the loop execute only once, after the loop completes
  • Any number of Python statements can be included in a loop

Example: Magician Messages
  • Simple output: Print each name from a list
  • Message output: Combine list values with strings using concatenation ( + )
  • String methods like .title() can format output within loops

Avoiding Indentation Errors

Understanding Indentation's Role
  • Python uses indentation (whitespace) to determine code structure
  • Indented lines following a for loop are considered part of that loop
  • Proper indentation is essential for correct program execution
  • Indentation makes code visually organized and readable

Common Indentation Errors

1. Missing Indentation After For Statement
  • Error Type: Syntax Error - "Expected an indented block"
  • Cause: No indentation provided for statement following for loop
  • Solution: Press Tab or add spaces to indent the statement
  • Impact: Program will not run

2. Forgetting to Indent Additional Lines
  • Error Type: Logical Error (no syntax error reported)
  • Cause: Some statements meant for the loop are not indented
  • Result: Unindented statements execute only once after loop completes, using only the last value from
    the loop variable
  • Solution: Indent all statements that should be part of the loop
  • Impact: Program runs but produces incorrect output

3. Unnecessary Indentation
  • Error Type: Syntax Error - "Unexpected indent"
  • Cause: Indenting lines that should not be part of any block
  • Solution: Remove extra whitespace from the beginning of the line
  • Impact: Program will not run

4. Missing Colon After For Statement
  • Error Type: Syntax Error - "Expected colon"
  • Cause: Forgetting the : at the end of the for statement
  • Solution: Add a colon at the end of the for line
  • Impact: Program will not run


Key Principle

The scope and execution context of a for loop is determined entirely by indentation levels. Any indented
line following a for statement is part of that loop; non-indented lines that follow are outside the loop.


Practical Application

  • Store related items in a list
  • Use for loops to process each item
  • Add personalized messages or perform operations on each element
  • Control which statements execute repeatedly versus once using indentation
  • Verify syntax (colons, indentation) before running code

Data Classification

Copying a List

Creating a True Copy Using Slicing:
  • To create an independent copy of a list, use the slice notation with empty indices: new_list =
    original_list[:]

  • This syntax tells Python to create a slice starting from the first item and ending with the last item,
    producing a complete copy
  • The copied list is a separate entity, not just another reference to the same list

Example - Copying Food Lists:
  • Original list my_foods contains: pizza, falafel, carrot cake
  • Using friend_foods = my_foods[:] creates an independent copy
  • Changes to one list do not affect the other list
  • When canoli is added to my_foods and ice cream is added to friend_foods , each list maintains only
    its own items


Incorrect Method - Creating References Instead of Copies

Assignment Without Slicing:
  • Using friend_foods = my_foods (without slices brackets) does not create a copy
  • Instead, it creates a second variable name pointing to the same list
  • Any modifications through either variable name affect the same underlying list
  • Both variables are aliases for the identical list object

Example - Reference Problem:
  • When canoli is appended to my_foods , it also appears in friend_foods
  • When ice cream is appended to friend_foods , it also appears in my_foods
  • This proves both variables reference the same list, not separate lists

Definition and Purpose:

Overview

This lecture covers the practical implementation of if statements in Python, focusing on how to use
conditional logic to control program flow. The session builds on previously discussed conditional tests and
introduces various structures for making decisions in code: simple if statements, if-else chains, if-
elif-else chains with multiple conditions, and multiple independent if statements.


Simple If Statements

  • Basic Structure: An if statement consists of the if keyword, followed by a conditional test that
    evaluates to True or False , and then the code block to execute if the condition is true
  • Execution Flow: If the conditional test evaluates to True , Python executes the code following the if
    statement. If it evaluates to False , Python skips the block and looks for an else block
  • Indentation: Proper indentation is critical in Python. All code within an if block must be indented
    from the if keyword. Code at the same indentation level as if is outside the block
  • Multiple Statements: An if block can contain multiple lines of code, as long as they are properly
    indented
  • Example: if age >= 18: followed by indented print statements will execute only when the condition
    is true


If-Else Statements

  • Purpose: if-else statements allow you to execute one action when a condition is true and a different
    action when the condition is false
  • Structure: The else block executes only when all preceding if / elif conditions return False
  • Advantages: Instead of having no output when a condition fails, the else block provides an
    alternative code path
  • Example: If a person's age is less than 18, one message prints; otherwise, a different message about
    being old enough to vote prints
  • Execution: Python checks the if condition first. Only if it's false does Python check for and execute
    the else block


If-Elif-Else Chains

  • Multiple Conditions: Used when you need to test more than two possible situations
  • Sequential Evaluation: Python executes only one block in an if-elif-else chain, testing conditions
    in order until one passes
  • Efficiency: Once a condition passes, Python executes that block's code and skips all remaining tests in
    the chain
  • Structure: Can have one if statement, multiple elif statements, and optionally one else
    statement
  • Example Use Case: An amusement park with different admission prices based on age groups (under
    4 free, 4-18 costs $5, 18+ costs $10, 65+ costs $3)

Multiple Elif Blocks

  • Flexibility: You can use as many elif blocks as needed to check multiple conditions
  • Code Optimization: Instead of writing separate print statements in each block, assign values to a
    variable within each condition, then use a single print statement after the entire chain
  • Benefits: This approach makes code more concise and easier to maintain—changes to output
    messages only require updating one print statement
  • Example: Check if age is under 4, then elif under 18, then elif under 65, then else for seniors—
    each assigns a different price value, followed by one print statement


Omitting the Else Block

  • Optional Else: Python does not require an else block at the end of an if-elif chain
  • Use Case: Sometimes it is clearer and more appropriate to use only if and elif statements without
    a catch-all else block
  • Advantage: Prevents executing code for invalid or unexpected data that doesn't match any specific
    condition
  • Example: For age validation, you might have if statements checking for specific age ranges without
    an else block, allowing the program to do nothing if no condition matches


Testing Multiple Conditions with Independent If Statements

  • When to Use: Use multiple independent if statements when you need to check all conditions and
    execute code for every condition that is true, not just the first one
  • Difference from If-Elif-Else: In an if-elif-else chain, Python stops after the first true condition.

  • Syntax: Each if statement is completely separate with no elif or else ; each can execute

  • Real-World Example: A pizzeria program checking for multiple toppings—if using if-elif-else , only
    the first topping would be added; with multiple if statements, all requested toppings are added
  • Code Structure:
      ◦ if-elif-else is appropriate when only one code block should run
      ◦ Multiple if statements are appropriate when multiple code blocks might need to run


Key Concepts and Best Practices

  • Indentation Matters: Python uses indentation to determine which statements belong to which block
  • Logical Testing: Use comparison operators ( == , != , > , < , >= , <= ) and logical operators ( and ,
     or , not ) to create conditions

  • Sequential Processing: Python always processes code from top to bottom, checking conditions in the
    order they appear
  • Efficiency vs. Completeness: Choose between if-elif-else chains (when only one condition
    should trigger) and multiple if statements (when all matching conditions should trigger)

Overview of Dictionaries and Looping

A Python dictionary can contain a few key-value pairs or millions of pairs. Since dictionaries often hold
large amounts of data, Python provides multiple methods to loop through them. The main approaches
include looping through key-value pairs, keys only, keys in order, or values only.


Looping Through All Key-Value Pairs

  • Method: Use the .items() function with a for loop
  • Syntax: for key, value in dictionary_name.items():
  • How it works: The .items() method stores both the key and its associated value into separate
    variables during each iteration
  • Example: In a favorite_languages dictionary, a for loop can access each person's name (key) and
    their programming language preference (value) simultaneously
  • Variable naming: You can use any variable names instead of "key" and "value" (e.g., "name" and
     "language" ) to make the code more readable


Looping Through All Keys in a Dictionary

  • Primary method: Use the .keys() function
  • Syntax: for name in dictionary_name.keys():
  • Important note: Using .keys() is actually optional because Python treats looping through a
    dictionary as looping through its keys by default
  • Simplified syntax: for name in dictionary_name: achieves the same result without explicitly calling
     .keys()

  • Practical use: Useful when you only need to work with keys and don't require the associated values
  • Checking key existence: The .keys() method can be combined with conditional statements to
    check if a specific key exists in the dictionary


Looping Through Dictionary Keys in Order

  • Method: Use the sorted() function combined with .keys()
  • Syntax: for name in sorted(dictionary_name.keys()):
  • Functionality: The sorted() function creates a copy of the keys and arranges them in alphabetical
    order before looping
  • Benefit: Allows you to display dictionary contents in a specific order without modifying the original
    dictionary
  • Process: Python lists all keys from the dictionary, sorts them alphabetically, and then loops through
    the sorted list

Topic 1: How the Input Function Works

Understanding the Input Function
  • The input() function pauses program execution and waits for user input
  • It accepts one string argument, which serves as a prompt displayed to the user
  • The user's response is stored as a string in a variable
  • Example: message = input("Tell me something and I will repeat it back to you")

Writing Clear Prompts
  • Prompts should be clear and easy to understand so users know what to enter
  • Prompts guide the user on what information is needed
  • Multi-line prompts can be created by storing a prompt in a variable and concatenating strings
  • Example:


   prompt = "If you tell us who you are, we can personalize the message you see.\n"
   prompt += "What is your first name? "
   name = input(prompt)


Using the int() Method for Numerical Input
  • The input() function treats all user input as strings, even if numbers are entered
  • To perform mathematical operations or comparisons, string input must be converted to integers using
    the int() method
  • Without conversion, Python cannot compare strings to numbers and will produce an error
  • Example: age = int(input("How old are you? "))
  • The int() function converts string representations of numbers to integer values
  • Once converted, numerical operations and comparisons can be performed
  • If non-integer values (like decimals) are entered, a ValueError will occur

The Modulo Operator ( % )
  • The modulo operator divides one number by another and returns the remainder
  • Syntax: number % divisor
  • Useful for determining if a number is even or odd
  • Example: if number % 2 == 0: checks if a number is even (remainder is 0)
  • Example: if number % 2 != 0: checks if a number is odd (remainder is not 0)

Topic 2: Introducing While Loops

Understanding While Loops
  • A while loop runs continuously as long as a specified condition is true
  • Unlike for loops that iterate a predetermined number of times, while loops depend on condition
    evaluation
  • Structure requires three components:
      ◦ Initialize: Set the starting value of a variable
      ◦ Condition: Specify when the loop should continue
      ◦ Update: Increment or modify the variable each iteration

While Loop Structure and Execution
Syntax:


   current_number = 1
   while current_number <= 5:
          print(current_number)
          current_number += 1


  • The += operator is shorthand (e.g., current_number += 1 equals current_number = current_number +
    1 )

  • The loop checks the condition before each iteration
  • If the condition is true, the code block executes; if false, the loop terminates
  • Example output for the above code: 1, 2, 3, 4, 5

Letting the User Control Program Flow
  • Programs can continue running until a user chooses to exit
  • A quit value is established to terminate the loop
  • Example implementation:


   prompt = "Tell me something: "
   prompt += "\nEnter 'quit' to end the program: "
   message = ""


   while message != "quit":
          message = input(prompt)
          if message != "quit":
              print(message)


  • The if statement prevents the quit command itself from being printed as output
  • The program continues requesting input until the user enters the quit value

Using a Flag

What is a Flag?
  • A flag is a variable (typically a Boolean) that controls program flow and determines whether the
    program should continue running
  • Flags help manage complex programs where multiple conditions could terminate execution
  • Common flag values are True (program active) or False (program stops)

Why Use Flags?
  • In complex programs like games, many events can trigger program termination (e.g., player runs out of
    ships, time runs out, protected cities destroyed)
  • Instead of testing multiple conditions in a single while statement, a flag monitors overall program
    status
  • Makes code cleaner and more maintainable

Practical Implementation
  • Set flag variable (e.g., active = True ) before the while loop
  • Write condition as while active:
  • Change flag to False when an exit condition is met
  • When flag becomes False , the while loop terminates automatically


Using Break to Exit a Loop

Break Statement Fundamentals
  • The break statement immediately exits a loop without executing remaining code
  • Provides direct flow control for exiting loops based on conditional tests

How Break Works
  • When Python encounters break , it exits the current loop entirely
  • Often used with while True: to create loops that run until a specific condition is met
  • The loop terminates immediately upon encountering break , regardless of the loop condition

Example Application
  • Prompt user to enter city names until they type "quit"
  • When "quit" is entered, the if statement triggers break
  • Python exits the loop and continues with code after the while block

Using Continue in a Loop

Continue Statement Purpose
  • The continue statement skips remaining code in the current iteration and returns to the loop's
    beginning
  • Useful for filtering or processing specific items within a loop

How Continue Works
  • When encountered, continue immediately goes back to the loop condition check
  • The rest of the loop body is skipped for that iteration
  • The loop continues normally with the next iteration

Practical Example
  • Loop counts from 1 to 10 but prints only odd numbers
  • For even numbers (divisible by 2), continue skips the print statement
  • For odd numbers, the print statement executes normally


Avoiding Infinite Loops

What Creates Infinite Loops
  • A loop with no exit condition (e.g., while True: without break )
  • Forgetting to increment or modify a counter variable
  • Missing flag updates that would terminate the loop

How to Prevent Infinite Loops
  • Every while loop must have a termination mechanism:
      ◦ A counter that eventually makes the condition false
      ◦ A flag that changes to False
      ◦ A break statement that executes
  • Double-check loop logic before running code

Handling Accidental Infinite Loops
  • In Google Colab, click the pause button to stop execution
  • Close the terminal window if running in command line
  • Review loop conditions to identify and fix the issue

    Lecture 27: Introduction to Functions in Python

This lecture introduces the concept of functions in Python as reusable blocks of code designed to perform
specific tasks. Functions improve code organization, readability, and maintainability by eliminating the
need to rewrite logic multiple times throughout a program.


Overview of Functions

  • Function Definition: A function is a named block of code that performs one specific job
  • Code Reusability: Functions allow you to write code once and call it multiple times, reducing errors
    and improving debugging
  • Benefits: Programs become easier to write, read, test, and maintain
  • Key Concept: Instead of repeating code, you simply call the function by name wherever needed


Defining a Function

  • Syntax: Use the def keyword followed by the function name, parentheses, and a colon
  • Example: def greet_user():
  • Function Body: All indented lines following the function definition constitute the body where logic
    code is written
  • Docstring: A comment between triple quotes that describes what the function does
      ◦ Example: """Display a simple greeting."""
  • Function Call: Execute the function by writing its name followed by parentheses
      ◦ Example: greet_user()


Parameters and Arguments

  • Parameters: Variables listed in the function definition (e.g., username in def greet_user(username): )
  • Arguments: Actual values passed to the function when calling it (e.g., "Arun" in
     greet_user("Arun") )

  • Terminology: Parameters and arguments are used interchangeably, though technically parameters
    are in the definition and arguments are in the function call
  • Requirement: The number of arguments passed must match the number of parameters defined
    (unless default values are used)


Passing Arguments: Positional Arguments

  • Definition: Arguments must be provided in the same order as parameters are defined in the function
  • Order Matters: The sequence of arguments is critical; mismatching order produces incorrect results
  • Example: describe_pet("hamster", "Harry") assigns "hamster" to animal_type and "Harry" to
     pet_name

  • Multiple Parameters: Functions can have multiple parameters, and all arguments must be supplied
    in the correct order
  • Error Handling: Providing fewer arguments than required parameters results in a TypeError

Passing Arguments: Keyword Arguments

  • Definition: Name-value pairs passed to a function where each argument explicitly associates a
    parameter name with its value
  • Example: describe_pet(animal_type="parrot", pet_name="Kyle")
  • Flexibility: Order does not matter when using keyword arguments because Python matches names to
    values
      ◦ describe_pet(pet_name="Kyle", animal_type="parrot") produces the same result as above
  • Clarity: Keyword arguments make code more readable by clarifying the role of each value
  • Usage: Keyword arguments free programmers from worrying about argument order


Default Values

  • Purpose: Assign a default value to a parameter so the argument becomes optional during function
    calls
  • Example: def describe_pet(pet_name, animal_type="dog"):
  • Usage: If no argument is provided for a parameter with a default value, Python uses the default
  • Overriding: An explicit argument in the function call overrides the default value
  • Parameter Order Rule: Parameters with default values must be listed after parameters without
    default values
      ◦ Incorrect: def func(param1="default", param2):
      ◦ Correct: def func(param1, param2="default"):
  • Simplified Calls: Default values reduce the number of arguments required in function calls


Equivalent Function Calls

Multiple ways to call the same function can produce identical results:

  • Positional Arguments Only: describe_pet("Willie", "dog")
  • Keyword Arguments Only: describe_pet(pet_name="Willie", animal_type="dog")
  • Mixed Arguments: describe_pet("Willie", animal_type="dog")
  • Reordered Keywords: describe_pet(animal_type="dog", pet_name="Willie")
  • Using Defaults: describe_pet("Willie") uses the default value for animal_type


Avoiding Argument Errors

  • Mismatched Arguments: Errors occur when the number of arguments provided does not match the
    function's expectations
  • Too Few Arguments: Providing fewer arguments than required parameters raises a TypeError
    indicating missing required positional arguments
  • Too Many Arguments: Providing more arguments than the function accepts raises a TypeError
    indicating too many positional arguments
  • Traceback Window: Python displays helpful error messages showing the location of the problem and
    which arguments are needed
  • Descriptive Naming: Using clear, logical names for functions and parameters makes error messages
    more useful and code easier to understand

Passing an Arbitrary Number of Arguments

Purpose and Use Cases
  • When building applications, the exact number of arguments needed is often unknown in advance
  • Users may provide varying amounts of information (e.g., different numbers of pizza toppings)
  • Python allows functions to accept any number of arguments using the asterisk ( * ) operator

Implementation
  • The asterisk before a parameter name (e.g., *toppings ) tells Python to create an empty tuple
  • The function collects all provided arguments into this tuple
  • A single asterisk handles arbitrary positional arguments

Example:


   def make_pizza(*toppings):
        """Print requested toppings"""
        print(toppings)


   make_pizza('pepperoni')           # Tuple with one item
   make_pizza('mushrooms', 'green peppers', 'extra cheese')            # Tuple with three items



Mixing Positional and Arbitrary Arguments

Key Rule
  • Parameters accepting arbitrary arguments must be placed last in the function definition
  • Python first matches positional and keyword arguments, then collects remaining arguments in the final
    parameter

Implementation
  • Define positional parameters first (e.g., size )
  • Place the arbitrary argument parameter last (e.g., *toppings )
  • Python assigns values sequentially to positional parameters before handling arbitrary arguments

Example:

Using Arbitrary Keyword Arguments

Purpose
  • Accept key-value pairs when the exact information needed is unknown in advance
  • Use double asterisk ( ** ) before the parameter name to create an arbitrary keyword argument
  • Python creates an empty dictionary to store these key-value pairs

Implementation
  • Double asterisk (e.g., **user_info ) indicates arbitrary keyword arguments
  • Use .items() method to iterate through key-value pairs
  • Build a dictionary with all received information

Example:


   def build_profile(first, last, **user_info):
        """Build a dictionary containing user information"""
        profile = {'first_name': first, 'last_name': last}
        for key, value in user_info.items():
              profile[key] = value
        return profile


   user_profile = build_profile('Albert', 'Einstein', location='Princeton', field='physics')
   print(user_profile)

    Lecture 31: Introduction to Classes in Object-Oriented

This lecture introduces classes, a fundamental concept in Python that enables object-oriented
programming (OOP). Classes serve as blueprints for creating objects that represent real-world things and
situations, allowing programmers to write more effective and organized software.


Overview of Object-Oriented Programming and Classes

  • Object-Oriented Programming (OOP) is one of the most effective approaches to writing software
  • Classes enable OOP by defining the general behavior and characteristics that a category of objects can
    share
  • Instantiation is the process of creating individual objects (instances) from a class
  • Each instance automatically has the general behavior defined in the class but can have unique traits


Class vs. Instance: Architectural Blueprint Analogy

  • A class is like an architectural blueprint of a house that defines general characteristics (bedrooms,
    kitchen, garage, etc.)
  • An instance is an actual physical house built from that blueprint with unique qualities (paint color,
    occupants, location)
  • From a single blueprint, multiple distinct instances can be created, each with different properties
  • Similarly, from one class definition, multiple instances can be created with different data values


Creating and Using a Class: The Dog Class Example

Class Structure:
  • Use the class keyword followed by the class name and a colon
  • By convention, class names are capitalized in Python
  • Include a docstring describing the class's purpose
  • Define methods (functions within a class) that represent behaviors and characteristics

Key Components of the Dog Class:
  • __init__ method: A special built-in Python method that automatically runs when creating an instance
      ◦ Takes self as the first parameter (automatically passed by Python, no argument needed)
      ◦ Initializes attributes by assigning values using self.attribute_name
  • sit() method: Prints that the dog is sitting
  • rollover() method: Prints that the dog is rolling over

Creating an Instance:
  • my_dog = Dog("Willie", 6)
  • When this line executes, Python automatically calls the __init__ method
  • Arguments are passed only for name and age parameters; self is passed automatically
  • Python returns an instance that is stored in the variable my_dog

Understanding the Self Parameter

  • self is required as the first parameter in all method definitions within a class

  • Python automatically passes self when calling methods, so no argument is provided for it

  • This gives each instance its own independent copy of the attributes

Overview

This session continues the discussion on classes in Python, building upon the foundational concepts of

Setting Default Values for Attributes

  • Every attribute in a class requires an initial value
  • Default values can be specified directly in the __init__ method without requiring them as parameters
  • Example: The odometer_reading attribute is initialized to 0 in the __init__ method, which means
    any car instance starts with zero miles
  • This approach is useful when you want consistent initial values across all instances


Modifying Attribute Values

There are three primary ways to modify attribute values:

1. Modifying Directly Through an Instance
  • Access attributes using dot notation: instance.attribute_name = new_value
  • Example: my_car.odometer_reading = 23
  • This directly changes the attribute value without any validation

2. Modifying Through a Method
  • Create a method that updates the attribute value
  • Can include validation logic to prevent invalid changes
  • Example: update_odometer() method includes logic to prevent rolling back the odometer reading (you
    cannot set a lower value than the current reading)
  • This approach allows for business logic enforcement

3. Incrementing an Attribute Value
  • Use a method that adds a value to the existing attribute rather than replacing it
  • Use the += operator for incrementing
  • Example: increment_odometer() method adds miles to the current reading
  • Useful for scenarios where you want to add to existing values rather than replace them


Inheritance in Python

Inheritance allows you to create a new class based on an existing class, enabling code reuse and
hierarchical relationships.

Key Concepts:
  • Parent Class (Superclass): The original class from which other classes inherit
  • Child Class (Subclass): A new class that inherits attributes and methods from the parent class
  • A child class automatically gains all attributes and methods of its parent class
  • Child classes can add new attributes and methods specific to their purpose

Syntax for Creating a Child Class:

   class ChildClass(ParentClass):
        # class definition



Initializing a Child Class with __init__ Method

  • The __init__ method in a child class must call the parent class's __init__ method
  • Use the super() function to establish the connection between parent and child classes
  • Syntax: super().__init__(parent_parameters)
  • The super() function tells Python to call the __init__ method from the parent class
  • Example: In the ElectricCar class, super().__init__(make, model, year) calls the Car class's
     __init__ method


Defining Attributes and Methods for Child Classes

  • Child classes can have their own unique attributes and methods
  • Example: ElectricCar has a battery_size attribute that regular Car instances do not have
  • Example: describe_battery() is a method specific to electric cars
  • Attributes and methods defined in a child class are only available to instances of that child class, not to
    parent class instances


Method Overriding

  • Child classes can redefine methods from the parent class
  • When you define a method in a child class with the same name as a parent class method, the child
    class version takes precedence
  • Example: fill_gas_tank() method in Car class can be overridden in ElectricCar class to indicate
    that electric cars don't need gas tanks
  • Python disregards the parent method and uses the child class method instead


Instances as Attributes

  • A class instance can be used as an attribute of another class
  • This allows for better organization and separation of concerns
  • Example: Instead of adding all battery-related attributes and methods to ElectricCar , create a
    separate Battery class
  • The ElectricCar class has a battery attribute that stores an instance of the Battery class
  • Access methods of the battery instance through: electric_car_instance.battery.method_name()

Benefits:
  • Keeps classes focused and manageable
