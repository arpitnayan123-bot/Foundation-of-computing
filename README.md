## ✦ What is The Atlas?

Class slides are static; memory isn't. **The Atlas** takes each course PDF and rebuilds
it as a dark-premium, single-page experience where concepts move: accounting equations
that balance themselves, guild ladders you can climb, Venn diagrams that shade the law
you click, bell curves that breathe. Every shelf keeps the same soul —

- **Living machines** — diagrams rendered as interactive Framer-Motion instruments, not figures
- **Practice walls** — the deck's own concept checks and answer keys, checked instantly
- **Pen-paper exam windows** — timed, navigable question banks with model explanations and scoring
- **A parchment-on-ink design system** — `#fffaf1` cards floating on `#3e2c1d` structure,
  one accent colour and one ambient "whisper" animation per shelf

### Shelf 01 · Foundations of Computing (FoC)

> From the IPO model to object-oriented Python — the whole course, alive.

Thirty-three chapters mirroring the IIT Jodhpur deck lecture-for-lecture (28 recorded
lectures + the classes finale), from the IPO model to object-oriented Python — with the
Knight Capital case file, the Netflix DIKW walkthrough, the indentation-law machine, an
interactive alias-vs-copy simulator, the records-lab pipeline, and **real CPython 3.12
running in the browser** so every code snippet is executable, not decorative.

- **Topics** — Course map & IPO · Data, classified · Case files · Algorithms · Hardware & Software · Python core · Lists, dicts & loops · Functions & Classes
- **Exam bank** — 160 questions · 6 pen-paper windows
- **Signature machines** — the DIKW pyramid, Knight Capital's burn-rate math, the alias-vs-copy simulator, the indentation-law error picker, the records-lab pipeline, the live Python runner

### Shelf 02 · Algorithmic Thinking in Business (ATB)

> Data structures & algorithms — no code, all logic.

Thirty-three chapters mirroring the course deck lecture-for-lecture (all 28 lectures, L1–L28,
in the deck's own order): flowcharts that animate
their own branches, the nine-property wall, memory-box machines, stacks and queues that
push and pop in front of you, a **hash table you can poke** until a collision happens, and
**all three O(n²) sorts — bubble, selection and insertion — racing on screen**, pass by pass.

- **Topics** — Course map & algorithms · 9 properties · Arrays & lists · Stacks & queues · Trees & graphs · Hashing & blockchain · Searching & the three sorts
- **Exam bank** — 51 questions · 8 pen-paper windows
- **Signature machines** — the flowchart runner, the stack & queue machines, the collision table, the selection & insertion sort players

### Shelf 03 · Financial Accounting (FA)

> Every rupee tells two stories — the whole course, in balance.

Twenty-nine lectures and thirty-three chapters mirroring the IIT Jodhpur deck lecture-for-lecture, where the accounting equation **balances itself as you watch**, T-accounts
post their debits and credits, the trial balance can be sorted, and prepaid expenses split
themselves across periods. Journal to final statements, without a single dead figure.

- **Topics** — Dual aspect & equation · Journal & ledger · Trial balance · Five statements · Adjusting entries · Trading account & GP
- **Exam bank** — 40 questions · 4 pen-paper windows
- **Signature machines** — the self-balancing equation, the posting T-accounts, the splitting prepaid

### Shelf 04 · Economic & Business History (EBH)

- **Topics** — Rules & players · License Raj · Agrarian & guilds · Trade routes · Industrial Revolution · Labor movement
- **Exam bank** — 40 questions · 4 pen-paper windows
- **Signature machines** — the guild ladder, the Silk Road speedometer, the Cottonopolis counter

## 📝 Pen-Paper Exam Simulators

Every shelf ships timed **pen-paper windows** — the exam, rehearsed honestly:

- ⏱ **A real countdown** with pause-safe progress and window navigation
- 🧭 **A question navigator** — jump anywhere, flag anything, see unanswered at a glance
- ✅ **Instant feedback** — pick an option and get *“Correct.”* or a gentle nudge, plus the
  **model explanation** written the way you'd want to write it on paper
- 🧮 **A running score** and a results summary when the window closes

**37 windows · 393 questions** across the six live shelves — sized to the real course
weight (FoC carries 120; every other shelf 30–40).

## 🎨 The Design System

One mould, six whispers. All shelves pour from the same parchment-on-ink system —
cards of `#fffaf1` on a `#3e2c1d` structure — and each shelf owns exactly two things:
an **accent** (amber, rose, emerald, gold, violet) and one minimal **ambience** animation
(`sweep · aura · scan · spotlight · shimmer · drift`). Nothing blinks for attention;
everything moves with intent. The landing shelf is a morphism bento — glass, clay, neo,
spotlight, holo and aurora cards frame the crazy-word title wall.

## ⚡ Quickstart

```bash
# install (bun recommended — npm/pnpm work too)
bun install

# run the dev server
bun run dev
# → http://localhost:3000  ·  landing shelf at #/atlas, each subject at #/subject/<id>

# quality gates
bun run lint        # eslint
bunx tsc --noEmit   # strict types
```

## 🗂 Project Structure

```text
src/
├── app/
│   └── page.tsx              # the Atlas router — hash-routes every shelf
├── components/
│   ├── atlas/                # the landing: subjects registry + morphism bento
│   │   ├── subjects.ts       #   ← the single source of truth for all shelves
│   │   └── AtlasLanding.tsx
│   ├── foc/ · atb/ · fa/     # one folder per subject:
│   ├── ebh/                  #   <X>App.tsx (shell + scroll-spy nav)
│   ├── stm/                  #   <X>Parts1-N.tsx (the chapters, as living machines)
│   │                         #   questions.ts (exam banks) + <X>ExamWindow.tsx
│   └── notes/                # shared primitives (Section, Reveal, quiz, footer…)
public/
└── atlas-logo.svg            # the animated mark — an open book rising into a globe
```

Adding a subject = **one entry in `subjects.ts` + one mount in `page.tsx`**. Nothing else changes.
