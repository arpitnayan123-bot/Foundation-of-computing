Lecture 2
What is Computing?
Computing is fundamentally different from
computers as devices. Computing is the
abstract process of solving problems through a
well-defined series of steps, taking information
as input, processing it, and producing useful
results. This concept predates modern
electronic computers by centuries.
Historical Examples of Computing:


Ancient Abacus (3000 BC): Merchants used this
tool to perform addition and subtraction,
demonstrating that computing existed before
electronic machines
Navigation Tables (1600s-1800s): Sailors used
pre-calculated tables to determine their
positions at sea by processing coordinates
through mathematical tables
Human Computers (World War II): Women
performed complex arithmetic calculations to
determine artillery trajectories, and their job title
was literally "computers"—the term referred to
humans before it referred to machines
These examples illustrate that computing is a
methodology, not dependent on any particular
technology.


The IPO Model: Foundation of All Computing
The IPO Model (Input-Process-Output) is the
fundamental principle underlying every
computing process:


Input: Raw data or information provided to the
system
Process: The execution of algorithms and logical
operations on the input
Output: The meaningful result produced after
processing
This model applies universally—from simple
calculators to artificial intelligence systems.
Understanding this model is essential because it
appears in every digital application and
deviceReal-World Examples of the IPO Model
Smartphone Applications:


Input: User touches and swipes on the screen
(e.g., selecting food items in a delivery app)
Process: App logic executes based on user
actions (e.g., adding items to cart, processing
payments)
Output: Visual feedback appears on the screen
for each action
Google Search Engine:


Input: Natural language query typed into the
search bar
Process: Algorithm searches billions of web
pages in milliseconds, ranking them based on
keyword relevance, page speed, mobile
friendliness, and domain trustworthiness
Output: Ranked search results displayed on the
screen
UPI (Unified Payments Interface):


Input: Amount to transfer and UPI PIN
Process: Bank verifies identity, checks account
balance, debits amount from sender's account,
credits amount to receiver's account
Output: Confirmation notifications sent to both
parties
Google Maps:


Input: Current location and destination address
Process: Shortest path algorithm evaluates
hundreds of possible routes, considering current
traffic, roadblocks, and other factors
Output: Recommended route displayed with
estimated travel time
YouTube Recommendation Engine:


Input: Video watched by user, watch duration,
and sections skipped
Process: Algorithm compares user behavior with
millions of other users globally, identifying
patterns in viewing habits (a machine learning
process)
Output: Personalized video recommendations
related to user's interests
Smartphone Autocorrect:


Input: Letters and words typed by the user
Process: Algorithm analyzes typed letters and
previous words, predicts next word based on
patterns learned from millions of user sentences
Output: Suggested next word for user
selectionComputing vs. Computer: A Critical
Distinction
Computing is the abstract intellectual concept of
problem-solving through defined, step-by-step
procedures. Computer is the physical electronic
tool that executes computing processes with
speed and precision.


Key differences:


Computing existed for thousands of years
before electronic computers were invented
Computing can be performed with pen and

Computers are fast executors of computing

When asked to define computing, avoid

Data: Raw, unprocessed facts and observations

Algorithm: Well-defined set of instructions that

Hardware: Physical electronic components that
execute instructions
Software: Programs and code that implement
algorithmsUnderstanding Data: The Foundation

"Patient's temperature is 38.5 degrees Celsius"

Understanding Data: Classification and
Organization
Overview
Data is classified into various types to determine
appropriate processing methods and analysis
techniques. Understanding these classifications
is fundamental to computing and data analysis,
as each type requires different handling
approaches and operations.


Main Classifications of Data

1. Structured vs. Unstructured vs. Semi-
   Structured Data
  Structured Data


Organized into rows (records) and columns
(fields) in a tabular format
Each field has a defined data type (number, text,
date, yes/no)
Enables easy searching, sorting, filtering, and
analysis operations
Examples: CSV files, Excel spreadsheets, Google
Sheets, database tables, bank transaction
records, student marksheets, hospital patient
registers, e-commerce order tables
Represents a smaller portion of global data
Unstructured Data


Does not follow a predefined format or
organization
Cannot be neatly placed into rows and columns
Comprises approximately 80% of all data
generated globally
Types include:
Text: emails, messaging chats, news articles,
customer reviews, social media posts
Images: photos, medical x-rays, satellite
imagery, ID card scans
Audio: voice calls, podcasts, music files, voice
notes
Video: CCTV footage, YouTube videos, recorded
lectures
Sensor data: raw IoT device readings without
labels
Processing requires specialized tools and
techniques like transformers for natural
language processing and computer vision for
imagesSemi-Structured Data


Falls between structured and unstructured data
Has some organizational markers but not in
tabular format
Examples: JSON files (used in web APIs), XML
files, HTML pages, emails (with fixed headers
but free-form body)
Allows for organization and analysis despite
lacking rigid row-and-column structure
2. Data Across Time: Cross-Sectional, Panel, and
Time Series Data
Cross-Sectional Data
Collected from multiple subjects (people, cities,
companies) at a single point in time
Captures a snapshot at one moment
Allows comparison across subjects but cannot
track individual changes over time
Examples: election polls, consumer surveys,
Amazon product feedback, census data, medical
studies comparing patient groups
Use case: survey of 500 students in Delhi on
June 1, 2025
Panel Data (Longitudinal Data)


Tracks multiple subjects over multiple time
periods in sequence
Combines breadth of cross-sectional data with
multiple time points
Enables both cross-subject comparison and
over-time trend analysis
More information-rich than cross-sectional or
time series data alone
Examples: monthly marks of students tracked
over six months, NREGA employment records
(collected yearly), IMF macroeconomic data
across countries over years, clinical drug trials,
school performance tracking
Allows analysis of which subject improved most
over time
Time Series Data


Collected for a single subject at multiple points
in time in sequence
Focus is on tracking one entity over different
time instances
Time is the key dimension, and sequence
matters
Reveals trends, cycles, and sudden changes
Examples: daily closing stock prices, weather
forecasting data, ECG heartbeat monitoring,
website traffic, epidemic spread and case
counts, smartphone step counter data,
electricity meter readings, financial market data
Note: Distinguished from panel data by tracking
only one subject rather than multiple subjects3.
Quantitative vs. Qualitative Data
Quantitative Data (Quant Data)


Numerical and measurable
Can be counted or measured
Two subtypes:
Discrete: Countable whole numbers (e.g.,
number of students: 30, number of goals: 3,
number of apps: 47)
Continuous: Any value within a range including
decimals (e.g., height: 172.4 cm, temperature:
36.8°C, time: 9.5 seconds)
Mathematical operations possible: addition,
subtraction, mean, median, standard deviation,
correlation
Advantages: quick and easy to analyze, less
prone to errors and biases, enables identification
of trends and patterns, results can be
generalized with representative sampling
Collection method: surveys
Answers questions like: what, how often, how
many, how much
Qualitative Data (Qual Data)


Categorical and non-numerical
Represents labels, categories, qualities, and
opinions
Two subtypes:
Nominal: Categories with no natural order (e.g.,
blood group A/B/AB/O, city of birth, phone
brand). Operations possible: mode, frequency
count, chi-square test
Ordinal: Categories with meaningful order but
unequal gaps (e.g., Amazon star ratings 1-5,
education level, customer satisfaction: poor/fair/
good/excellent)
Includes natural language text, feedback, and
opinions
Advantages: provides in-depth insights and
contextual information
Collection method: interviews
Answers questions like: how, why
Limitations: analysis more prone to researcher
bias, requires thematic or content analysis,
interpretation is subjective4. Primary vs.
Secondary Data
Primary Data: Collected directly from the source
for a specific purpose
Secondary Data: Already collected data
repurposed for a different analysis
Importance of Data Classification
Understanding data types is crucial for
programmers and data analysts because:


Type of data determines which operations are
meaningful and valid
Cannot perform mean or median on nominal or
ordinal data
Averaging city of birth would yield no meaningful
insight
Proper classification ensures appropriate
analysis methods and reliable conclusions

Introduction to Algorithms
Definition and Core Concept
An algorithm is the intellectual core of computing
—a finite, unambiguous, step-by-step procedure
for solving a well-defined problem. Algorithms
exist independently of computers; computers
are simply machines that execute algorithms
very rapidly.


Historical Context
The term "algorithm" derives from Muhammad
Ibn Musa Al-Qarizmi, a 9th-century Persian
mathematician
His work on arithmetic and algebra introduced
systematic problem-solving methods
The word "algebra" also originates from his book
title
Algorithms existed before modern computers
(e.g., women "computers" calculating artillery
trajectories during World War IIImportance of
Algorithm Quality
The quality of computing depends on algorithm
quality, not just hardware power
A well-optimized algorithm can work effectively
even with less computing power
A bad algorithm produces wrong or slow results
regardless of hardware capability
Researchers in the 1990s conducted AI research
with limited computing power by optimizing
algorithms
Simple Algorithm Example: Determining Odd or
Even Numbers
Start
Read number n
Divide n by 2 and check remainder
If remainder = 0: print "even"
If remainder ≠ 0: print "odd"
End
Five Essential Properties of Algorithms
1. Finiteness
  Algorithm must terminate after a finite
  number of steps
  Cannot run forever or loop infinitely
  Example of bad algorithm: "Divide n by 2 until
  n equals 0" (will never reach exactly 0)

2. Definiteness (Unambiguity)
  Every instruction must be precisely and clearly
  defined with no room for interpretation or
  subjectivity
  Same step must produce identical results
  every time
  Bad example: "Add a little bit of salt"
  (subjective)
  Good example: "Add exactly 5 grams of salt"
  (precise and objective)

3. Input
  Algorithm may have zero or more inputs
Inputs are values given before or during
execution
Examples:
Finding maximum of two numbers requires 2
inputs
Computing factorial requires 1 input (the
number)
Sorting a list requires the list as input
Displaying "Hello World" requires 0 inputs4.
Output
Algorithm must produce at least one output
(result of computation)
Without output, the algorithm is pointless
Examples:
Maximum algorithm outputs the larger number
Factorial algorithm outputs the factorial value
Sorting algorithm outputs the sorted list
Navigation algorithm outputs step-by-step
route
4. Effectiveness
  Every step must be basic enough to be
  performed by a person using pen and paper
  (in principle)
  No step should require infinite resources or be
  physically impossible
  Resource requirements should be optimal and
  practical
  Bad examples:
  Finding the largest prime number (numbers
  are infinite)
  Asking 1 billion users simultaneously
  (requires infinite resources)
  Good examples:
  Comparing two numbers to find which is
  bigger (basic, executable operation)
  Common Algorithmic Structures
  Do-While Loop: Executes code then checks
  condition
  If-Else Statement: Executes different code
  based on condition
  While Loop: Checks condition before
  executing code
  All algorithmic structures follow the same
  foundational principles and will be covered in
  detail during Python programming lessons.

Processing Units: The Brain of Computing
CPU (Central Processing Unit)
The general-purpose brain of the computer that
executes instructions sequentially at high speed.


Key Components:
ALU (Arithmetic Logical Unit): Performs
arithmetic operations (addition, subtraction,
multiplication, division) and logical operations
(AND, OR, NOT, comparisons)
Control Unit (CU): Orchestrates instruction
fetching from memory, decoding, and directing
operations to ALU and other units; decides
which instruction executes next when multiple
applications run simultaneously
Performance Metrics:


Modern CPUs execute 3 to 5 billion instructions
per second
Speed measured in GHz (gigahertz)
Multiple cores enable simultaneous task
processing (4, 8, 16, or up to 24 cores in modern
processors)
Role in Programming: When running a Python
program, the interpreter translates high-level
code into machine instructions that the CPU
executes.


GPU (Graphics Processing Unit)
Designed differently from CPUs, optimized for
parallel processing of large datasets.


Architecture Differences:


CPU: Few powerful cores (4-24), optimized for
complex sequential tasks
GPU: Thousands of small, simple cores,
optimized for performing the same operation on
millions of data points simultaneously
Original Purpose: Graphics rendering and video
game pixel color and position calculations


Current Applications in AI:


Training neural networks for computer vision
and machine vision
Large language models and image generators
Performing the same mathematical operations
on billions of numbers simultaneously
Memory: Where Data Resides
Memory stores data currently being used by the
computer. Two primary types exist with different
characteristics.


RAM (Random Access Memory) - Fast and
Temporary
Characteristics:


Volatile: Contents are lost when power is cut
Fast: Data accessed in nanoseconds, much
faster than storage
Limited Storage: Typical phones have 6-12 GB;
laptops have 8-32 GB
Function: The computer's working memory,
similar to a physical desk while studying
Usage: When apps are opened, they load from
storage into RAM for execution. Variables, lists,
and objects exist in RAM during runtime and are
cleared when programs close.


ROM (Read-Only Memory) - Permanent and
Immutable
Characteristics:


Non-volatile: Instructions remain intact even
without power
Permanent: Instructions burned at factory and
cannot be changed
Primary Memory: Like RAM, part of the main
memory system
Contents:


Firmware and bootloader (program running
before OS starts)
Fixed instructions that ensure system
initialization
Secondary Storage - Permanent Data Storage
Where data lives permanently, even when
devices are powered off. This is where
documents, images, videos, Python files, music,
and databases are kept.


Types of Secondary Storage:


SSD (Solid State Drive): Modern replacement for

Lecture 11
Introduction to Lists in Python
A list is a collection of items arranged in a
particular order. Lists can contain any type of
elements, such as letters, numbers, or names,
and the items do not need to be related to each
other in any way.


Overview of Lists
Lists are fundamental data structures in Python
that allow you to store multiple values in a single
variable. The naming convention for lists
typically uses plural forms (e.g., letters, digits,
names, motorcycles) since they contain multiple
elements.


Creating and Printing Lists
Syntax: Lists are created using square brackets
with elements separated by commas
Example: bicycles = ['Trek', 'Cannondale', 'Red
Line', 'Specialized']
Output: Printing a list displays all its elements in
the same format they were stored
print(bicycles) outputs: ['Trek', 'Cannondale', 'Red
Line', 'Specialized']
Accessing Elements in a List
Index Positions: Lists are ordered collections
where each element has a specific position
The first element is at index 0 (not 1)
The second element is at index 1
The third element is at index 2, and so forth
Syntax: Access elements using the list name
followed by the index in square brackets
bicycles[0] returns 'Trek'
bicycles[1] returns 'Cannondale'
Formatting Elements: You can apply string
methods to accessed elements
bicycles[0].title() converts 'trek' to 'Trek'
.upper() converts to uppercase; .lower() converts
to lowercase
Accessing the Last Element
Negative Indexing: Python provides a special
syntax for accessing elements from the end of
the list
bicycles[-1] always returns the last element (in
this case, 'Specialized')
bicycles[-2] returns the second-to-last element
bicycles[-3] returns the third-to-last element, and
so on
Benefit: This method is useful when you don't
know the list's length or when working with
dynamic lists
Using Individual List Values
String Concatenation: You can combine list
values with strings using the concatenation
operator (+)
Example: message = 'My first bicycle was a ' +
bicycles[0].title() + '.'
Output: 'My first bicycle was a Trek.'
Modifying List Elements
Changing Values: To modify an element, use the
list name, index, and assignment operator
Syntax: list_name[index] = new_value
Example: motorcycles[0] = 'Ducati' replaces
'Honda' with 'Ducati'
Effect: The new value replaces the old value at
that specific position
Adding Elements to a List
Appending Elements
Method: The append() method adds a new
element to the end of the list
Syntax: list_name.append(new_value)
Example: motorcycles.append('Ducati') adds
'Ducati' at the end
Building Dynamic Lists: You can start with an
empty list and add elements one by one
motorcycles = []
motorcycles.append('Honda')
motorcycles.append('Yamaha')
motorcycles.append('Suzuki')
Inserting Elements at Specific Positions
Method: The insert() method adds an element at
a specified position
Syntax: list_name.insert(index, new_value)
Example: motorcycles.insert(0, 'Ducati') places
'Ducati' at the beginning (index 0)
Example: motorcycles.insert(1, 'Ducati') places
'Ducati' at the second position
Effect: All elements at and after the specified
index shift one position to the right
Removing Elements from a List
Using the del Statement
Purpose: Permanently deletes an element from a
list when you know its position
Syntax: del list_name[index]
Example: del motorcycles[0] removes the first
element
Characteristics: Once deleted, the value cannot
be retrieved
Using the pop() Method
Purpose: Removes an element from the list
while retaining access to that value
Syntax: list_name.pop() (removes the last
element) or list_name.pop(index) (removes
specific position)
Example: popped_motorcycle =
motorcycles.pop() removes and stores the last
element
Default Behavior: Without an index, pop() always
removes the last element
Stack Concept: Think of a list as a stack of
plates where pop() removes from the top (end)
Practical Use: If you need to use the removed
value elsewhere in your code, use pop()
Example: first_owned = motorcycles.pop(0)

Introduction to For Loops
Purpose: For loops allow iteration through all

Problem Solved: Eliminates the need to write

Benefit: Code automatically adapts if list length

for [variable_name] in [list_name]:
[statement to execute]
for: keyword indicating loop start
variable_name: stores each individual value from
the list during each iteration
in: keyword connecting variable to list
list_name: the list to iterate through
: (colon): required syntax element that marks the
beginning of the loop body
How For Loops Work
Python takes the first value from the list and
stores it in the variable
Executes all indented statements below the for
line
Moves to the next value and repeats the process
Loop terminates automatically when all list
elements are processed
Multiple Statements in Loops
You can include multiple statements within a
loop
All indented lines following the for statement are
executed for each list element
Non-indented lines after the loop execute only

Any number of Python statements can be

Message output: Combine list values with

Avoiding Indentation Errors
Understanding Indentation's Role
Python uses indentation (whitespace) to
determine code structure
Indented lines following a for loop are
considered part of that loop
Proper indentation is essential for correct
program execution
Indentation makes code visually organized and
readable
Common Indentation Errors

1. Missing Indentation After For Statement
  Error Type: Syntax Error - "Expected an
  indented block"
  Cause: No indentation provided for statement
  following for loop
  Solution: Press Tab or add spaces to indent
  the statement
  Impact: Program will not run

2. Forgetting to Indent Additional Lines
  Error Type: Logical Error (no syntax error
  reported)
  Cause: Some statements meant for the loop
  are not indented
  Result: Unindented statements execute only
  once after loop completes, using only the last
  value from the loop variable
  Solution: Indent all statements that should be
  part of the loop
  Impact: Program runs but produces incorrect
  output

3. Unnecessary Indentation
  Error Type: Syntax Error - "Unexpected indent"
  Cause: Indenting lines that should not be part
  of any block
  Solution: Remove extra whitespace from the
  beginning of the line
  Impact: Program will not run

4. Missing Colon After For Statement
  Error Type: Syntax Error - "Expected colon"
  Cause: Forgetting the : at the end of the for
  statement
  Solution: Add a colon at the end of the for line
  Impact: Program will not run
  Key Principle
  The scope and execution context of a for loop
  is determined entirely by indentation levels.
  Any indented line following a for statement is
  part of that loop; non-indented lines that
  follow are outside the loop.

Incorrect Method - Creating References Instead

Assignment Without Slicing:


Using friend_foods = my_foods (without slices

Instead, it creates a second variable name
pointing to the same list
Any modifications through either variable name
affect the same underlying list
Both variables are aliases for the identical list
object
Example - Reference Problem:


When canoli is appended to my_foods, it also
appears in friend_foods
When ice cream is appended to friend_foods, it
also appears in my_foods
This proves both variables reference the same
list, not separate lists

Overwriting Entire Tuples:

Lecture 27
Introduction to Functions in Python
This lecture introduces the concept of functions
in Python as reusable blocks of code designed
to perform specific tasks. Functions improve
code organization, readability, and
maintainability by eliminating the need to rewrite
logic multiple times throughout a program.


Overview of Functions
Function Definition: A function is a named block
of code that performs one specific job
Code Reusability: Functions allow you to write
code once and call it multiple times, reducing
errors and improving debugging
Benefits: Programs become easier to write, read,
test, and maintain
Key Concept: Instead of repeating code, you
simply call the function by name wherever
needed
Defining a Function
Syntax: Use the DEF keyword followed by the
function name, parentheses, and a colon
Example: def greet_user():
Function Body: All indented lines following the
function definition constitute the body where
logic code is written
Docstring: A comment between triple quotes
that describes what the function does
Example: """Display a simple greeting."""
Function Call: Execute the function by writing its
name followed by parentheses
Example: greet_user()
Parameters and Arguments
Parameters: Variables listed in the function
definition (e.g., username in def
greet_user(username):)
Arguments: Actual values passed to the function
when calling it (e.g., "Arun" in greet_user("Arun"))
Terminology: Parameters and arguments are
used interchangeably, though technically
parameters are in the definition and arguments
are in the function call
Requirement: The number of arguments passed
must match the number of parameters defined
(unless default values are used)
Passing Arguments: Positional Arguments
Definition: Arguments must be provided in the
same order as parameters are defined in the
function
Order Matters: The sequence of arguments is
critical; mismatching order produces incorrect
results
Example: describe_pet("hamster", "Harry")
assigns "hamster" to animal_type and "Harry" to
pet_name
Multiple Parameters: Functions can have
multiple parameters, and all arguments must be
supplied in the correct order
Error Handling: Providing fewer arguments than
required parameters results in a TypeError
Passing Arguments: Keyword Arguments
Definition: Name-value pairs passed to a
function where each argument explicitly
associates a parameter name with its value
Example: describe_pet(animal_type="parrot",
pet_name="Kyle")
Flexibility: Order does not matter when using
keyword arguments because Python matches
names to values
describe_pet(pet_name="Kyle",
animal_type="parrot") produces the same result
as above
Clarity: Keyword arguments make code more
readable by clarifying the role of each value
Usage: Keyword arguments free programmers
from worrying about argument order
Default Values
Purpose: Assign a default value to a parameter
so the argument becomes optional during
function calls
Example: def describe_pet(pet_name,
animal_type="dog"):
Usage: If no argument is provided for a
parameter with a default value, Python uses the
default
Overriding: An explicit argument in the function
call overrides the default value
Parameter Order Rule: Parameters with default
values must be listed after parameters without
default values
Incorrect: def func(param1="default", param2):
Correct: def func(param1, param2="default"):
Simplified Calls: Default values reduce the
number of arguments required in function calls
Equivalent Function Calls
Multiple ways to call the same function can
produce identical results:


Positional Arguments Only: describe_pet("Willie",
"dog")
Keyword Arguments Only:
describe_pet(pet_name="Willie",
animal_type="dog")
Mixed Arguments: describe_pet("Willie",
animal_type="dog")
Reordered Keywords:
describe_pet(animal_type="dog",
pet_name="Willie")
Using Defaults: describe_pet("Willie") uses the
default value for animal_type
Avoiding Argument Errors
Mismatched Arguments: Errors occur when the
number of arguments provided does not match
the function's expectations
Too Few Arguments: Providing fewer arguments
than required parameters raises a TypeError
indicating missing required positional arguments
Too Many Arguments: Providing more
arguments than the function accepts raises a
TypeError indicating too many positional
arguments
Traceback Window: Python displays helpful error
messages showing the location of the problem
and which arguments are needed
Descriptive Naming: Using clear, logical names
for functions and parameters makes error
messages more useful and code easier to
understand
