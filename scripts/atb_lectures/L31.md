# Lecture 31: 31: Integration of Searching and Sorting in Web Search

Lecture 31: Integration of Searching and Sorting in
Web Search
This lecture explores how modern web search combines searching and sorting principles, using Google's
PageRank algorithm as a foundational example of how basic algorithmic concepts drive trillion-dollar
products.
Traditional Search vs. Web Search
Traditional Search Characteristics
Focuses on finding and retrieving exact matches
Concerned with existence verification and item location
Uses linear and binary search algorithms
Returns results only when there is an exact match (sensitive to spelling, spacing, and character
changes)
Web Search Characteristics
Emphasizes relevance rather than exact matches
Searches across complex data structures like graphs and networks
Finds connections between documents
Presents results in order of relevance and authority
Focuses on top results rather than complete sorted datasets
Evolution of Search Engine Technology
Early Search Engines (Late 1990s - Early 2000s)
Yahoo and AltaVista relied on keyword frequency
Pages with repeated keywords ranked higher, regardless of relevance
Users often had to search through 8-10 pages to find relevant information
Easily manipulated through keyword stuffing
Google's Innovation
Created by Larry Page and Sergei Brin at Stanford University
Patented in 1998 as the PageRank Algorithm
Named both after Larry Page's surname and the concept of ranking web pages
Addressed relevance issues by introducing a new ranking methodology
PageRank Algorithm: Core Principles
The PageRank algorithm is built on two fundamental mechanisms:
1. Weighted Voting Mechanism
Links as Endorsements: A link from one page to another represents an endorsement of authority

Unequal Votes: Not all links carry equal weight; links from authoritative sources (like Wikipedia or
established news outlets) carry more weight than links from random blogs
Authority Dilution: When a page links to multiple pages, its authority is divided among them. If an
authoritative page links to 100 different sites, each site receives only 1/100th of that page's authority
Outcome: Higher authority increases a page's importance, but this authority must come from
connections with other authoritative pages
2. Random Surfer Model
Link Following: 85% probability that a user will continue following links from one page to another
Random Jump: 15% probability that a user will abandon the current path and navigate to a
completely new URL or search term
Probabilistic Assumption: Based on analysis of large-scale user behavior patterns
Practical Application: These percentages are incorporated into the ranking formula to reflect realistic
user behavior
PageRank Algorithm: Implementation Steps
Represent Web Pages as Directed Graph: Each web page becomes a node, and each hyperlink
becomes a directed edge showing the direction of the link
Assign Initial Rank: Begin with equal initial rank for all nodes (e.g., 0.25 for four pages)
Apply Distribution Formula: Use the formula:
New Rank = (0.15/N) + 0.85 × (Rank received from other pages)
N = total number of web pages
Distribute Outgoing Rank: Divide a page's rank equally among all its outgoing links
Calculate for All Nodes: Update ranks for every page based on incoming links
Iterative Recalculation: Repeat the calculation multiple rounds using previous weights only for
calculation purposes
Reach Stabilization: Continue until ranks stabilize (typically around 13-14 rounds)
Sort by Final Rank: Present web pages to users in order of their final PageRank scores
Numerical Example
With four web pages (A, B, C, D) connected as: A→B, A→C, B→C, C→A, D→C
First Round Calculations:
Page A: Receives full weight from C (one outgoing link) → Rank ≈ 0.25
Page B: Receives 0.125 from A (shared with C) → Rank ≈ 0.14375
Page C: Receives from A (0.125), B (0.25), D (0.25) → Rank ≈ 0.56875
Page D: Receives no incoming links → Rank ≈ 0.0375
Pattern Observed: Pages with more incoming links from authoritative sources receive higher ranks, while
pages with no incoming links receive minimal ranks.

Led to "Google Dance" phenomenon where rankings fluctuated drastically between updates

Real-Time Processing Era (2010-Present)
Implemented incremental web crawling instead of static snapshots
Uses dynamic graph integration for new and modified pages
New web pages integrated into rankings within shorter timeframes
Still uses PageRank as the foundational algorithm but incorporates hundreds of additional machine

Modern PageRank Implementation
Foundational Algorithm: PageRank remains the core principle
Enhanced Parameters: Over 200+ ranking factors now included beyond basic PageRank
Machine Learning Integration: AI-driven signals enhance relevance and ranking accuracy
Continuous Evolution: Algorithm parameters continuously adjusted based on user behavior and
feedback
Key Takeaways
Web Search as Integrated Discipline: Modern web search represents a combination of searching
(finding relevant information through graph traversal) and sorting (ranking results by importance and
relevance)
Relevance Over Completeness: Users care about top results, not sorting all available information
Connection Matters: In web search, how pages connect to each other determines their importance
as much as their content
Strong Foundations Drive Innovation: PageRank's success demonstrates that solid algorithmic
foundations allow for continuous enhancement and scaling to massive datasets
Iterative Innovation: Google's evolution from batch processing to real-time updates shows that
successful products require continuous experimentation and refinement beyond the initial algorithm
