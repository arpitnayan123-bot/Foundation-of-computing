# Lecture 18: 18: Introduction to Non-Linear Data Structures

Lecture 18: Introduction to Non-Linear Data Structures
This lecture covers the fundamental concepts of non-linear data structures, specifically trees and graphs,
which are essential for representing hierarchical and interconnected data in real-world applications.
Overview of Linear vs. Non-Linear Data Structures
Linear Data Structures
Arrays, linked lists, stacks, and queues allow sequential access to elements
Elements are accessed one by one in a predetermined order
Examples: Array indexing (0, 1, 2...) or following links in a linked list
Similar to following a single path or receiving guidance from one person
Non-Linear Data Structures
Trees and graphs allow multiple pathways and connections
Multiple options exist at each point in the structure
Better representation of real-world scenarios with choices and alternatives
Example: Educational path selection (online/offline → college selection → degree choice)
Trees: Hierarchical Structure
Basic Concept and Definition
A tree is a hierarchical data structure with a root node at the top and branches extending downward
Follows a reverse structure compared to real trees (root at top, leaves at bottom in computer science)
Fundamental property: A child node can have only one parent node
One parent can have multiple child nodes
Key Terminology
Tree Components:
Root Node: The top-most node with no parent
Parent Node: A node that has child nodes connected to it
Child Node: A node that is connected to a parent node
Leaf Node: A terminal node with no children
Edges: The connections between parent and child nodes
Subtree: Any subset of nodes and edges forming a smaller tree within the larger tree
Tree Measurements:
Depth: Number of edges from the root to a specific node (root has depth 0)
Height: The maximum depth of any leaf node in the tree (also equal to the number of edges from root
to the deepest leaf)
Real-World Applications of Trees
Family Trees: Hierarchical representation of ancestral relationships (patriarchal structure)

Tree Traversal Methods
Depth-First Traversal (DFS): Continues down one path until reaching a leaf, then backtracks to explore
other paths
Three variations based on root position:
Pre-order Traversal: Root → Left → Right
Example: A B D C (visit root first, then left subtree, then right subtree)
In-order Traversal: Left → Root → Right
Example: D B E A C (visit left subtree, root, then right subtree)
Implementation: Uses Stack data structure
Post-order Traversal: Left → Right → Root
Example: D E B C A (visit left subtree, right subtree, then root)
Breadth-First Traversal (Level-order): Visits nodes level by level from top to bottom, left to right
Example: A B C D E (level 1, then level 2, then level 3)
Implementation: Uses Queue data structure
Graphs: General Connectivity Structure
Definition and Components
A graph is a more general non-linear data structure that allows multiple parent-child relationships and
circular connections.
Graph Representation:
Mathematically represented as G = (V, E)
V (Vertices): Set of nodes in the graph
E (Edges): Set of connections between vertices
Terminology:
Vertex: A node in the graph (equivalent to node in tree)
Edge: A connection between two vertices
Degree: Number of edges connected to a vertex

Types of Graphs
Directed vs. Undirected:
Undirected Graph: Edges have no direction; relationship is bidirectional (e.g., two-way roads, mutual
friendship)
Directed Graph: Edges have direction; relationship is one-way (e.g., one-way traffic, following on
social media)
In-degree: Number of edges coming into a vertex
Out-degree: Number of edges going out from a vertex
Social media influencer example: High in-degree (many followers) vs. out-degree (following others)
Weighted vs. Unweighted:
Unweighted Graph: All edges have equal value
Weighted Graph: Edges have different values/weights representing strength, distance, or cost (e.g.,
road distances, relationship closeness)
Connected vs. Disconnected:
Connected Graph: All vertices are reachable from any other vertex through some path
Disconnected Graph: Some vertices cannot be reached from others (isolated components)
Example: Road connectivity in India (mainland connected, but islands disconnected)
Cyclic vs. Acyclic:
Cyclic Graph: Contains at least one path that starts and ends at the same vertex
Acyclic Graph: Contains no cycles; is a tree structure
Real-World Applications of Graphs
Social Networks: Connections between people, influencer networks for marketing
Road Networks: Cities as vertices, roads as edges (weighted with distances)
Web Pages: Pages as vertices, hyperlinks as directed edges
Biological Networks: Species relationships, food chains
Recommendation Systems: Users and products connected based on preferences
Graph Traversal Methods
Depth-First Search (DFS): Explores as far as possible along one branch before backtracking
Process:
Start at a vertex and push it onto a stack
Pop the top vertex from stack and mark as visited
Find all unvisited neighbors of the popped vertex
Push unvisited neighbors onto the stack
Repeat until stack is empty
Implementation: Uses Stack data structure

Use case: Checking if certain nodes are reachable; finding connected components
Breadth-First Search (BFS): Explores all immediate neighbors before moving to the next level
Process:
Start at a vertex and enqueue it into a queue
Dequeue a vertex from the front and mark as visited
Find all unvisited neighbors of dequeued vertex
Enqueue unvisited neighbors into the queue
Repeat until queue is empty
Implementation: Uses Queue data structure
Use case: Finding shortest paths; exploring neighborhood relationships
Practical Example: DFS with Stack Implementation
For a graph starting from vertex A:
Push A, pop and mark visited
Find neighbors P and Q, push both
Pop P, mark visited, find neighbor X, push it
Pop X, mark visited, find neighbor S, push it
Continue until all vertices are visited and stack is empty
Result: Visits vertices in depth order (A → P → X → S → C → Q → Y → R → B)
Practical Example: BFS with Queue Implementation
For the same graph starting from vertex A:
Enqueue A, dequeue and mark visited
Find neighbors P and Q, enqueue both
Dequeue P, mark visited, find neighbor X, enqueue it
Dequeue Q, mark visited, find neighbor Y, enqueue it
Continue level by level
Result: Visits vertices by level (A → P, Q → X, Y → S, R → C, B)
Key Takeaways
Trees are specialized graphs with one-parent constraint, useful for hierarchical data
Graphs are more general structures allowing multiple connections and cycles
Traversal methods (DFS and BFS) differ in approach but both can be implemented using linear data
structures (Stack and Queue respectively)
Linear data structures (stack and queue) support traversal of non-linear structures, demonstrating their
interconnected importance
Tree traversals vary by node visit order (pre-order, in-order, post-order)
Graph properties (directed, weighted, connected) determine their real-world applicability
