Lecture 15: Understanding Graphs: A Non-Linear Data
Structure
Overview
This lecture introduces graphs as a non-linear data structure used to capture relationships between nodes,
contrasting them with trees which represent hierarchical structures. Graphs are more suitable when
modeling realistic scenarios where nodes can have multiple connections and relationships.
Trees vs Graphs: Key Differences
Trees
Represent hierarchical relationships
Each node (except root) has exactly one parent
Single-sided perspective (useful for organizational charts or file systems)
Limited to parent-child relationships
Graphs
Represent relationships between equal entities
Nodes can have multiple connections
Capture complex, multi-directional relationships
More suitable for realistic scenarios with interconnected entities
Example: A complete family tree considering both parental sides requires a graph structure because
children have two parents, violating the tree constraint of single parent per child.

Graph Components and Representation

Standard Notation: G = (V, E)
V = set of all vertices
E = set of all edges connecting vertices
Example
V = {A, B, C, P, Q, R, S, X, Y}
E = {(C,S), (A,P), (A,Q), (B,R), (S,P), (Q,R), (S,X), (P,X), (Q,Y), (R,Y), (X,Y)}
Graph Properties
Degree of a Vertex
The number of edges directly connected to a vertex
Calculated by counting all edges emanating from that vertex
Example: In a family graph, vertex P connected to A, S, and X has a degree of 3
Types of Relationships
Graphs can represent various relationship types beyond hierarchy:
Spouse relationships
Cousin relationships
Collaboration partnerships
Any multi-directional connection
Key Takeaways
Definition: Graphs capture relationships between nodes without imposing hierarchical constraints
Representation: Graphs are formally defined as G = (V, E) where V lists vertices and E lists edges
Flexibility: Nodes can connect to any number of other nodes
Practical Application: Graphs model real-world networks like social media, family structures,
organizational collaborations, and transportation systems more accurately than trees
