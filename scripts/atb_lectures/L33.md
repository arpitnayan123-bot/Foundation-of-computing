Lecture 33: Sorting Algorithms and Web Search
Relevance
This lecture covers the fundamental concepts of sorting algorithms and their practical application in web
search technology, demonstrating how data structures and algorithms work together in real-world
systems.
Overview of Sorting
Sorting is the process of arranging elements in a specific order based on application requirements. It can
be ascending, descending, or based on specific parameters (such as price or rating on e-commerce
websites). Sorting is essential because many search algorithms require data to be organized, making it a
crucial component of data structures and algorithms.
Five Main Sorting Algorithms
1. Bubble Sort
Concept: Elements are compared pairwise and swapped if they are in the wrong order, with larger
elements "bubbling" to their correct positions.
Process:
Compare adjacent elements starting from the first pair
Swap if the first element is larger than the second
Move to the next pair
After each complete pass through the list, at least one element is in its correct position
Repeat until the entire list is sorted
Key Characteristics:
Simple logic and easy to implement
Performs immediate swaps after each comparison
Time Complexity: O(n²) — not suitable for large datasets
No additional space required
2. Selection Sort
Concept: The algorithm selects the smallest element from the unsorted portion and places it in the
correct position.
Process:
Assume the first unsorted element is the minimum
Compare it with all remaining unsorted elements
Mark the smallest element found (no immediate swap)
Once the smallest element is identified, swap it with the first position of the unsorted portion
Move to the next unsorted position and repeat
Key Characteristics:
Differs from bubble sort in that comparison happens before swapping

3. Insertion Sort
Concept: Elements are taken one at a time and inserted into their correct position in an already-sorted
portion of the list.
Process:
Start with the second element as the first key
Compare the key with sorted elements (from right to left)
Shift larger elements one position to the right
Insert the key into its correct position
Move to the next unsorted element and repeat
Key Characteristics:
Useful when data is continuously growing with new elements being added
Resembles how books are shelved in physical libraries
Requires multiple comparisons but positions elements more efficiently
Time Complexity: O(n²) — but with fewer operations in certain scenarios
Practical for small lists and growing datasets
4. Merge Sort
Concept: Uses a divide-and-conquer approach by recursively dividing the list into smaller sublists, sorting
them, and then merging them back together.
Process:
Divide the list into roughly equal halves recursively until individual elements remain
Merge pairs of sorted sublists by comparing first elements of each sublist
Place the smaller element in the merged list and advance that sublist's pointer
Continue until all elements from both sublists are merged
Repeat merging at each level until one fully sorted list remains
Key Characteristics:
More complex to understand but more efficient for large datasets
Requires additional space for creating sublists during division
No swaps needed; only division and merging operations
Time Complexity: O(n log n) — significantly better than O(n²)
Space Complexity: O(n) — requires extra memory for sublists
5. Quick Sort
Concept: Uses divide-and-conquer by selecting a pivot element and partitioning the list around it.
Process:
Select a pivot element (can be any element; often the last, first, or median)
Partition the list so elements less than the pivot go to the left and elements greater go to the right
Recursively apply the same process to left and right sublists
The pivot is now in its correct sorted position

Practical Application: Google's PageRank Algorithm
Concept Integration
Web search combines searching, sorting, and graph algorithms to rank pages by relevance rather than
simply checking existence or finding a single item.
How PageRank Works
Key Principles:
Link Connectivity: Pages linked to multiple other pages are more relevant
Quality of Links: Links from highly-ranked pages carry more weight than links from lesser-known
pages
Link Distribution: When a page links to multiple other pages, its ranking weight is divided equally
among them
PageRank Calculation
Formula: New Rank = 0.15/n + 0.85 × (sum of ranks received from other pages)
Where:
0.15 represents 15% of users randomly jumping to new pages
0.85 represents 85% of users following links from current pages
n is the total number of web pages
Process:
Initialize all pages with equal rank (1/n)

Key Takeaways
Sorting Fundamentals: Understanding multiple sorting approaches reveals the complexity trade-offs
between simplicity and efficiency
Divide and Conquer: Merge sort and Quick sort leverage this strategy for superior performance on
large datasets
Practical Relevance: Sorting and searching algorithms form the foundation of real-world applications
like web search
Complexity Matters: The difference between O(n²) and O(n log n) becomes critical as data scales
Algorithm Selection: The choice of algorithm depends on dataset size, memory constraints, and
specific application requirements
