# Lecture 32: 32: Understanding the Relationship Between Algorithms, AI, and Machine Learning

Lecture 32: Understanding the Relationship Between
Algorithms, AI, and Machine Learning
This concluding lecture explores the connections between algorithms, artificial intelligence, machine
learning, and deep learning, demonstrating where each approach is most effectively applied in real-world
business scenarios.
Overview of Algorithms and Structured Problems
Algorithms are most effective for structured, well-defined problems:
Algorithms are organized steps that convert data into desired output
They work best when both input and output are clearly defined and predictable
Common business applications include:
Accounting and financial calculations (asset classification, profit calculations)
Payroll processing (salary, deductions, allowances)
CGPA calculations (grade conversion to numerical values)
Enterprise Resource Planning (ERP) systems
Limitations of algorithms:
Real-life tasks are often unstructured and based on practice and experience (e.g., tea making, cooking)
Unstructured problems may require input from multiple sources or expert judgment
Market analysis, product launches, and sentiment analysis involve uncertain data and unclear solutions
Expert Systems: Codifying Expert Knowledge
Definition and approach:
Expert systems are complex rule-based algorithms, not true AI systems
They capture expert decision-making by shadowing and interviewing domain specialists
Knowledge is converted into if-then rules for decision-making
Healthcare example:
Medical diagnosis required rules based on observed doctor practices
A patient with fever and cough may indicate viral infection, flu, COVID-19, or pneumonia depending on
additional symptoms
Rules expand dramatically: if fever + cough + runny nose + sore throat = likely viral infection
If fever + cough + difficulty breathing + loss of taste/smell = possible COVID-19
Characteristics:
Still algorithmic in nature with hard-coded, pre-defined rules
Cannot learn or adapt after implementation
Can provide reasoning by citing which rule was applied
Backend always controlled by solution designers and programmers
Widely used in 1980s-2000s before machine learning became prevalent

Machine Learning: Pattern Recognition from Data
Key differences from traditional algorithms:
Machine learning algorithms create models that make decisions, rather than algorithms making
decisions directly
Requires labeled training data where both inputs and expected outputs are known
Complex statistics are applied to identify patterns in data
The ML workflow:
Training data (labeled input-output pairs) is provided
ML algorithm processes training data to create a predictive model
Trained model is validated
Model is then used for actual decision-making
When to use machine learning:
Patterns are difficult to define explicitly
Relatively large datasets are available (gigabytes)
Output/desired outcome is clearly known (classification, regression)
Examples: loan default prediction, customer segmentation by known criteria
Advantages over expert systems:
More efficient pattern recognition
Can handle complex relationships between multiple variables
Models can be updated with new data
Deep Learning: Handling Complex, Unstructured Data
Neural network foundation:
Based on how the human brain works with interconnected neurons
When neurons fire (activate), they create pathways and patterns
The brain learns through consolidating these neural pathways
Repeated activation of pathways solidifies learning (e.g., learning to ride a bike)
Key characteristics of deep learning:
Uses artificial neural networks with multiple hierarchical layers
Requires very large datasets (terabytes or more)
Does not require labeled output data in many cases
Explores data connections without predefined outcome categories
Can work with highly unstructured, complex problems
When to use deep learning:
Pattern complexity is very high
Very large amounts of training data are available
Output/desired segments are unclear or unknown
Examples: image recognition, video analysis, customer segmentation by unknown criteria, abnormality
detection in medical scans

Why deep learning became popular:
Historical limitation: required large computing power and data (theoretical since 1980s-90s)
Modern enabler: widespread internet data availability and cloud computing resources
Generative AI: Creating New Content
Definition and distinction:
Generative AI is a product, not a learning technique
Built on self-supervised deep learning (model improves itself during training)
Requires massive datasets (complete internet content, digitized books)
Continuously releasing new versions as models train on additional data
Capabilities:
Generates new content: text, images, audio, video, code
Used for creating personalized health reports, recommendations, and novel outputs
Examples: ChatGPT, Google Gemini, Anthropic Claude
Training requirements:
Needs all available human knowledge and continuously seeks more data
Companies actively scan and digitize historical books to increase training data
Practical Application Hierarchy
Algorithm approach:
Explicitly programmed steps and rules
Example: Railway system calculating shortest route between stations
Expert system approach:
Encodes expert knowledge as rules
Example: Manufacturing system identifying machine faults from sensor readings using engineer-
provided rules
Machine learning approach:
Statistical pattern recognition with labeled data
Clear, structured output desired
Example: Bank predicting loan default probability using customer data
Deep learning approach:
Neural network-based pattern recognition
Large unstructured datasets
Unclear or complex output definitions
Example: Security system detecting suspicious human activity in video footage
Generative AI approach:
Self-improving deep learning
Generates novel content
Example: News organization drafting articles from large text collections

Healthcare Example: Integrated Approach
Single healthcare scenario with multiple solutions:
Algorithm: Calculate BMI using height and weight formula
Expert system: Apply medical rules to determine obesity, considering gender, regional variations, and
medical history
Machine learning: Predict diabetes risk probability using age, BMI, lifestyle, genetics, and medical
history
Deep learning: Analyze medical scans to detect abnormalities in diabetic and obese patients
Generative AI: Create personalized health reports with dietary recommendations and treatment
options
Key Takeaway: Choosing the Right Approach
The principle: Use the simplest, most economical solution appropriate for the problem
Simple calculations: use a calculator, not an AI system
Structured, rule-based problems: use algorithms or expert systems
Pattern recognition with labeled data: use machine learning
Complex unstructured problems with massive data: use deep learning
Creating new content: use generative AI
This course provides foundational algorithmic thinking to understand where each technology fits in real-
world business applications. Future specialized courses on machine learning, deep learning, and
generative AI will build upon these fundamentals.
