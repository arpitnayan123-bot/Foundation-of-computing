# Lecture 26: 26: Selection Sort: A Comprehensive Overview

Lecture 26: Selection Sort: A Comprehensive Overview
This lecture covers selection sort, one of the fundamental sorting algorithms that builds on the concepts
previously learned from bubble sort. Selection sort operates by repeatedly finding the smallest (or largest)
element from the unsorted portion of a list and placing it in its correct position.
Core Concept and Mechanism
Basic Principle: Selection sort selects one element at a time and places it in its correct position
through swapping
Classical Implementation: Finds the minimum element from the unsorted portion and swaps it to the
front
Process Flow:
Start at the first position and assume it contains the smallest element
Compare this element with all remaining elements to the right
When a smaller element is found, mark it as the new minimum
After traversing the entire unsorted portion, swap the minimum with the starting position
Move to the next position and repeat the process
Execution with Numerical Example
Using the array [10, 5, 8, 4, 3, 2]:
Pass 1: Identify 2 as the minimum among all elements, swap it with 10 → [2, 5, 8, 4, 3, 10]
Pass 2: Identify 3 as the minimum from position 2 onward, swap with 5 → [2, 3, 8, 4, 5, 10]
Pass 3: Identify 4 as the minimum from position 3 onward, swap with 8 → [2, 3, 4, 8, 5, 10]
Pass 4: Identify 5 as the minimum from position 4 onward, swap with 8 → [2, 3, 4, 5, 8, 10]
Final Result: Array is sorted after n-1 passes
Alphabetical Sorting Application
Selection sort can be applied to alphabetical data where letters are compared lexicographically (A < B <
C ... < Z). The algorithm works identically—finding the minimum (earliest) letter and placing it in correct
position before moving to the next unsorted portion.
Variants of Selection Sort
Minimum Selection Sort (Classical):
Searches for the smallest element starting from the beginning
Places minimum elements at the front of the list progressively
Maximum Selection Sort:
Searches for the largest element starting from the end
Begins from the last position and works backward
Places maximum elements at the end of the list

Bidirectional Selection Sort:
Performs both minimum and maximum search in a single pass
Finds minimum from the front and maximum from the back simultaneously
Places both elements in correct positions in one pass
Reduces number of passes by half compared to unidirectional variants
Time Complexity Analysis
All Variants: O(n²) complexity
Why Bidirectional Doesn't Improve Complexity: Although passes are reduced by half, the total
number of comparisons remains the same because comparisons still need to traverse from both ends
to the middle
Practical Impact: For larger lists, O(n²) complexity makes selection sort inefficient despite its
simplicity
Comparison with Bubble Sort
Similarity: Both are O(n²) algorithms
Key Difference in Swaps:
Bubble sort may perform multiple consecutive swaps for the same element in a single pass (up to
n-1 swaps)
Selection sort performs only one swap per pass after finding the minimum/maximum
Advantage: Selection sort is more efficient in terms of the number of swaps performed
Key Takeaways
Selection sort is fundamentally based on selecting one element per pass and placing it in its correct
position
The algorithm uses swapping to achieve sorting with minimal operations per iteration
Despite having multiple variants (minimum, maximum, bidirectional), all maintain O(n²) time
complexity
Selection sort is suitable for educational purposes and small datasets but should be avoided for larger
lists due to quadratic complexity
While better than bubble sort in terms of swap operations, it remains impractical for real-world
applications with large datasets
