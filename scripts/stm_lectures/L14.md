# Lecture 14: Overview of Normal and Continuous Probability Distributions

This lecture extends practical probability problems using normal and standard normal probability distributions, along with an introduction to exponential distribution for real-world business applications.
Normal Probability Distribution
Fundamentals and Requirements
To solve probability problems, three key requirements must be met:
- Identify the underlying distribution (typically normal for natural phenomena)
- Determine the mean (μ)
- Determine the standard deviation (σ)
With these two parameters, any probability for any value can be estimated
Converting to Standard Normal Distribution (Z-Score)
Formula: Z = (X - μ) / σ
Purpose: Standardize different normal distributions to a common scale, allowing easy comparison across different problems with different means and standard deviations Example: A firm with mean 150 and standard deviation 60 asking about P(X > 200) yields the same Z- score as a firm with mean 1,500 and standard deviation 600 asking about P(X > 2,000) Both calculations result in Z = 0.83
Using the Standard Normal Table
- The standard normal table provides cumulative probabilities for Z values ranging from -3.4 to +3.4
Key reference values:
- Z = 0 corresponds to probability 0.50 (mean divides distribution equally)
- Z = 2 corresponds to probability 0.9772
Negative Z values: Use symmetry property where P(Z ≤ -a) = P(Z ≥ a) = 1 - P(Z ≤ a)
Practical Application Example: Football Player Weights
Given: Mean = 200 pounds, Standard Deviation = 25 pounds
Question: P(Weight > 250 pounds)?
Calculation: Z = (250 - 200) / 25 = 2
From table: P(Z ≤ 2) = 0.9772
Answer: P(Z > 2) = 1 - 0.9772 = 0.0228 or 2.28%
Intuitive Understanding
- When estimating values less than the mean: probability should exceed 50%
- When estimating values greater than the mean: probability should be less than 50%
- Use this logic to verify if calculated answers are reasonable
Estimating Ranges
- For probability between two values, calculate Z-scores for both boundaries
- Use symmetry: P(a ≤ X ≤ b) = P(Z ≤ Z₂) - P(Z ≤ Z₁)
Example with salary range 34,000 to 46,000 (mean 40,000, σ = 5,000):
- Z₁ = -1.2, Z₂ = 1.2
- P(-1.2 ≤ Z ≤ 1.2) = 2 × P(Z ≤ 1.2) - 1
Reverse Probability: Finding Values Given Probabilities
Concept
- Instead of finding probability for a given value, find the value that corresponds to a specific probability
- Formula rearranged: X = μ + Z × σ
Application Example: Reorder Point Decision
Goal: Limit stockout probability to no more than 5%
Process: Find Z-value that cuts off 0.05 in the right tail (Z ≈ 1.645) Given mean = 15 gallons, σ = 6 Calculation: X = 15 + (1.645 × 6) = 24.87 ≈ 25 gallons Business Impact: By increasing stock from 20 to 25 gallons, stockout probability decreases from 20% to 5%, fulfilling 15% more demand
Business Value of Statistical Approach
- Eliminates guesswork in inventory management
- Prevents overpurchasing (storage costs, capital ties, spoilage) and underpurchasing (lost sales)
- Enables data-driven decision-making for customer satisfaction and cost optimization
Using Excel for Probability Calculations
- NORM.DIST function: Arguments include X value, mean, standard deviation, and cumulative (TRUE for probability distribution)
- NORM.S.DIST function: Used with Z-scores directly
- While Excel simplifies calculations, understanding the Z-table is essential for conceptual comprehension
Uniform Probability Distribution
Characteristics
- Probability density function: f(x) = 1 / (b - a)
- Represents equal probability across all values in a range
- Example: Range 2 to 6 gives probability density = 1/4
Exponential Probability Distribution
Purpose and Applications
Describes time between events or time to complete tasks
Common applications:
- Time between vehicle arrivals at toll booths
- Time required to complete tasks
- Distance between defects in highways
- Waiting times in service lines
Key Properties
- Mean equals standard deviation (μ = σ)
- Distribution is right-skewed with skewness = 2
- Probability density function: f(x) = (1/μ) × e^(-x/μ)
- Cumulative function: P(X ≤ x) = 1 - e^(-x/μ)
Practical Example
Given: Mean time between car arrivals = 3 minutes
Question: P(Time between arrivals ≤ 2 minutes)?
Answer: Approximately 48% probability
Application: Petrol pump owner can plan staffing and break schedules
Learning Curve Application
- Demonstrates improvement with practice: solving similar problems becomes faster
- Follows exponential probability distribution pattern
- Validates the principle that "practice makes perfect"
Relationship Between Exponential and Poisson Distributions
Key Distinction
- Poisson Distribution: Describes the number of occurrences within a specific interval
- Exponential Distribution: Describes the length/time between occurrences
Complementary Applications
At a service station:
- Use exponential distribution to estimate duration until next customer arrival
- Use Poisson distribution to estimate total number of customers in a given time period
Together these distributions support design decisions for:
- Waiting line systems
- Service stations and hospitals
- Resource allocation based on historical arrival data
Practical Value
- With historical data providing mean values and known arrival patterns, managers can estimate both frequency and timing of events
- Enables effective capacity planning and service level optimization
