# Lecture 10: Overview of Random Variables and Discrete Probability Distributions

This lecture covers fundamental concepts in probability theory, focusing on random variables, probability distributions, expected values, and variance, with applications to discrete probability models.
Random Variables
Definition and Concept
- A random variable is a numerical description of the outcome of a statistical experiment
- A statistical experiment involves activities where outcomes are not identical but fall within certain bounds (e.g., rolling a die produces outcomes between 1-6)
Types of Random Variables
Discrete Random Variables: Assume a finite number of values or an infinite sequence of values with no values possible between consecutive numbers
- Examples: Number of people, number of TVs sold (0, 1, 2, 3, 4), family size, number of customers arriving
- Cannot take fractional values (e.g., cannot sell 1.5 TVs)
Continuous Random Variables: Can take any value within an interval or collection of intervals
- Examples: Distance from home to store, temperature, height
- Can assume infinite decimal values between any two numbers (e.g., 1.001, 1.1, 1.2)
Business Example
Let X = number of TVs sold at a store in one day
X can take discrete values: 0, 1, 2, 3, 4 (limited by stock availability) This is discrete because partial TV sales are impossible
Probability Distribution of Discrete Random Variables
Definition
- A probability distribution describes how probabilities are distributed across all possible values of a random variable
- Shows the relationship between each value the random variable can assume and its corresponding probability
Key Properties
- Each probability P(X) must be greater than or equal to 0
- The sum of all probabilities must equal 1: ΣF(X) = 1
- Represents the complete sample space of the experiment
Methods to Represent Probability Distribution
- Tables
- Graphs/visual representations
- Mathematical formulas
Empirical Discrete Probability Distribution
Concept
- Developed from observed data collected over time
- Uses the relative frequency method to assign probabilities
- Based on real-world observations rather than theoretical assumptions
Calculation Method
- Probability = (Number of favorable outcomes) / (Total number of observed outcomes)
- Example: If zero TVs were sold on 80 days out of 200 observed days, P(X=0) = 80/200 = 0.4
Example Application
Observed TV sales over 200 days:
- 0 TVs sold: 80 days (P = 0.40)
- 1 TV sold: 50 days (P = 0.25)
- 2 TVs sold: 40 days (P = 0.20)
- 3 TVs sold: 10 days (P = 0.05)
- 4 TVs sold: 20 days (P = 0.10)
Formula-Based Probability Distributions
Definition
- Mathematical formulas that directly calculate probabilities without requiring empirical observation
- Scientists and statisticians have developed standard formulas for common distributions
Common Discrete Probability Distributions
- Uniform Distribution
- Binomial Distribution
- Poisson Distribution
- Hypergeometric Distribution
Uniform Probability Distribution
- All values of the random variable are equally likely
- Formula: F(X) = 1/n (where n = number of possible values)
Examples:
- Coin toss: X can be heads or tails; F(X) = 1/2 for each outcome
- Die roll: X can be 1, 2, 3, 4, 5, or 6; F(X) = 1/6 for each outcome
Expected Value (Mean) of a Random Variable
Concept
- The expected value represents the most common or central value a random variable is likely to assume
- Measures the central location of the probability distribution
- Often does not equal any actual value the random variable can take
Calculation
- Expected Value (E(X) or μ) = Σ[X × F(X)]
- This is a weighted average where weights are probabilities
- Formula: μ = Σ X · P(X)
Example
TV sales data:
E(X) = (0 × 0.40) + (1 × 0.25) + (2 × 0.20) + (3 × 0.05) + (4 × 0.10) E(X) = 0 + 0.25 + 0.40 + 0.15 + 0.40 = 1.2 TVs per day Interpretation: On average, 1.2 TVs are sold daily, though actual daily sales vary
Variance and Standard Deviation
Variance Calculation
- Variance (σ²) = Σ[(X - μ)² × F(X)]
- Measures the spread or dispersion of the probability distribution around the mean
Standard Deviation
- σ = √Variance
- Represents the average deviation from the expected value
Example Application
For TV sales with mean μ = 1.2:
- Calculate (X - μ)² for each value
- Multiply by corresponding probability F(X)
- Sum to get variance
- Take square root to find standard deviation
Significance
- Helps understand the reliability and consistency of the expected value
- Larger variance indicates greater uncertainty in outcomes
- Smaller variance indicates more predictable outcomes
Additional Topics Covered
Bivariate Distributions
- Examines relationships between two random variables simultaneously
Covariance
- Measures how two random variables move together
- Important for understanding correlations
Financial Portfolio Applications
- Uses probability distributions to analyze investment returns
- Applies covariance to optimize portfolio allocation
