# Lecture 17: Understanding Sampling and Sampling Distributions

Overview
This lecture introduces the concepts of sampling and sampling distributions, explaining why sampling is essential for understanding population characteristics without examining entire populations. The lecture covers the fundamental principles of random sampling, point estimation, and practical applications using real-world examples.
Key Concepts and Definitions
Element: The entity on which data is collected
Population: Collection of all elements of interest
Sample: A subset of the population
Sampled Population: The population from which the sample is drawn Frame: A list of elements from which the sample will be selected
Why Sampling is Necessary
Practical Reasons:
- Impossible to test entire population: Testing complete populations is often medically, physically, or practically impossible (e.g., draining all blood from a body)
- Saves time: Faster results enable quicker decision-making
- Reduces cost: Less testing means fewer resources required
- Avoids destruction: Testing samples prevents unnecessary destruction of products (e.g., tire testing)
- Enables inference about populations: Allows reliable conclusions about large populations by examining representative samples
Real-World Examples:
- Blood samples: A 5-7 ml blood sample provides a complete blood profile estimate
- Cooking rice: One spoonful indicates whether the entire pot is cooked properly
- Tire testing: Selected tires are tested to verify quality standards without testing every unit
Types of Populations and Sampling
Finite Populations
- Can be listed completely (e.g., organization rosters, student classes, inventory numbers)
- Simple Random Sample: Every element has equal probability of selection; each possible sample of size n has the same probability of being selected
- Sample size notation: Small n = sample size; Capital N = population size
Sampling Methods
- Sampling with Replacement: Elements can appear in sample more than once
- Sampling without Replacement: Most common in industry; each element selected only once to ensure variability and true population characteristics
Infinite Populations
- Cannot be completely listed (frame cannot be constructed)
- Generated by ongoing processes with no upper limit (e.g., bank transactions, customers entering a store, phone calls to help desk)
- Sample selection requires ensuring: elements come from population of interest and are selected independently
Point Estimation
Point estimation uses sample data to compute a sample statistic that estimates a population parameter.
Common Point Estimators
- x̄ (Sample Mean): Point estimator of population mean (μ)
- S (Sample Standard Deviation): Point estimator of population standard deviation (σ)
- p̂ (Sample Proportion): Point estimator of population proportion (p)
Example: College Admissions
A college received 900 applications with SAT scores and housing preferences:
Sample of 30 applicants (using random numbers):
- Sample mean SAT score (x̄) = 1,684
- Sample standard deviation (S) = 85.2
- Sample proportion wanting housing (p̂) = 0.67
Actual population of 900 applicants:
- Population mean (μ) = 1,697
- Population standard deviation (σ) = 87.4
- Population proportion wanting housing (p) = 0.72
The sample estimates were very close to actual population values, demonstrating the effectiveness of proper sampling.
Target Population vs. Sampled Population
Target Population: The population about which inferences are desired Sampled Population: The actual population from which the sample is drawn Critical requirement: These two populations must be in close agreement for valid inferences Practical Considerations:
- Sampling context must match inference goals (e.g., sampling during holiday season for holiday buying behavior)
- Multiple samples from different locations/times provide more representative estimates
- Bias must be avoided; samples should represent the entire population rather than anomalies or outliers
Practical Application Using Excel
Process:
- Generate random numbers using RAND BETWEEN function to assign each population element a random value
- Sort by random numbers and select required sample size (e.g., first 50)
- Calculate sample statistics: average salary, standard deviation, proportion of employees with training
- Compare with population statistics to verify estimation accuracy
Example Results:
- Sample average salary: $72,370; Population average: $71,800
- Sample standard deviation: $3,063; Population standard deviation: $4,000
- Sample proportion trained: 0.60; Population proportion: 0.60
The sample provided reliable estimates while saving time and resources in data collection and analysis.
Key Takeaways
- Proper sampling methods provide reliable estimates of population characteristics without examining entire populations
- Random sampling ensures unbiased representation of the population
- Point estimators (mean, standard deviation, proportion) effectively estimate population parameters
- Target and sampled populations should align closely for valid statistical inferences
- Excel enables automated random sample selection and statistical calculation for practical applications
