# Lecture 11: Bivariate and Discrete Probability Distributions

Overview
This lecture covers the progression from univariate probability distributions (involving a single random variable) to bivariate probability distributions (involving two random variables that vary together). The lecture then explores two essential discrete probability distributions used in management applications:
binomial and Poisson distributions.
Bivariate Probability Distribution
- Definition: A probability distribution involving two random variables that take different values simultaneously
- Example: De Carlo Motors dealership sales data from two locations (Genoa and Saratoga) tracked over 300 days
- Reading the data: Can be interpreted horizontally (by dealership row) or vertically (by dealership column) to understand joint frequencies
- Converting to probability: Divide all frequencies by total observations (300) to create a bivariate probability distribution
Expected Value and Variance with Two Variables
- Uses the same formula approach as univariate distributions
- Calculate mean (expected value) and variance for total sales across both dealerships
- Formula: E(S) = Σ(S × P(S)), where S is total sales and P(S) is the probability
Covariance and Correlation
Covariance
- Measures the association between two random variables
- Formula: Cov(X,Y) = [Var(X+Y) - Var(X) - Var(Y)] / 2
- Positive covariance indicates that when one variable increases, the other tends to increase as well
- Example: Covariance of 0.135 between the two dealerships shows positive association
Correlation Coefficient
- Provides a standardized measure of relationship strength
- Range: -1 to +1
- Formula: r = Cov(X,Y) / (σₓ × σᵧ)
- A coefficient of 0.1295 indicates a weak positive relationship
- Correlation of 0 indicates no relationship between variables
- Similar to previous correlation concepts but applied to random variables
Binomial Probability Distribution
Conditions for Binomial Distribution
A binomial distribution applies only when all four of the following properties are satisfied:
1. Sequence of n identical trials: The experiment consists of repeated, identical trials (e.g., tossing a
- coin n times, testing n products)
2. Two possible outcomes: Each trial results in either success or failure with no third option
  - Cannot use binomial for test matches (win, lose, or draw)
  - Can redefine outcomes if necessary (e.g., "not winning" = failure)
3. Constant probability of success: Probability p remains the same across all trials
  - Called the stationarity assumption
  - Applicable only when the system is stable and relatively unchanging
  - Example: Production line testing works only when system is stable
4. Independent trials: Outcome of one trial does not affect another trial
Binomial Probability Function
Formula: P(X=x) = [n! / (x!(n-x)!)] × p^x × (1-p)^(n-x)
Components:
- First part [n! / (x!(n-x)!)] = number of experimental outcomes with exactly x successes in n trials
- Second part p^x × (1-p)^(n-x) = probability of a particular sequence with x successes
Binomial Distribution Parameters
- Expected value (mean): E(X) = n × p
  - Represents average number of successes over n trials
- Variance: Var(X) = n × p × (1-p)
- Standard deviation: σ = √[n × p × (1-p)]
Only two values needed: n (number of trials) and p (probability of success)
Example Application: Employee Turnover
Scenario: Electronics company experiences 10% annual turnover. What is the probability that exactly one out of three randomly selected employees will leave?
- n = 3 (employees selected)
- x = 1 (employees leaving)
- p = 0.10 (probability of leaving)
- Result: P(X=1) = 0.2430 or 24.30%
Cumulative Binomial Probabilities
- Represents probability that event occurs up to a certain number (e.g., less than 3)
- Statistical tables and Excel provide predefined cumulative probability values for quick reference
- Easier than manual calculation using the formula repeatedly
Poisson Probability Distribution
When to Use Poisson Distribution
- Estimates the number of occurrences over a specified interval of time or space
- Assumes infinite possible discrete values (0, 1, 2, 3, ...)
Common applications:
- Number of phone calls arriving at a call center per hour
- Number of vehicles arriving at a toll booth per hour
- Number of defects (knots) in lumber per linear feet
- Number of patients arriving at emergency room per hour
Conditions for Poisson Distribution
Only two properties required (simpler than binomial):
1. Equal probability across intervals: Probability of occurrence is the same for any two intervals of
- equal length
2. Independent occurrences: Occurrence or non-occurrence in one interval is independent of any other
- interval
Poisson Probability Function
Formula: P(X=x) = (μ^x × e^(-μ)) / x!
Components:
- x = number of occurrences in the interval
- μ (mu) = mean number of occurrences in the interval
- e = mathematical constant (approximately 2.71828)
- x! = x factorial
Poisson Distribution Parameters
- Mean (Expected value): E(X) = μ
- Variance: Var(X) = μ
- Key property: Mean equals variance (unique feature of Poisson distribution)
- Standard deviation: σ = √μ
Important Notes
- Only one parameter needed: μ (mean occurrences in interval)
- For very large x values, P(X=x) approaches 0 (becomes negligible)
- Probabilities become approximately zero for unlikely extreme values
Example Application: Emergency Room Arrivals
Scenario: Hospital emergency room receives average of 6 patients per hour on weekend evenings. What is probability of exactly 4 arrivals in 30 minutes?
- Original rate: μ = 6 per hour
- For 30 minutes (half hour): μ = 3
- x = 4 (desired arrivals)
- Result: P(X=4) = 0.168 or 16.8% probability

Conclusion
Binomial and Poisson distributions are the primary discrete probability distributions used in management applications. Understanding when to apply each distribution and their key parameters (mean and variance) enables managers to make probability-based decisions regarding customer acquisition, quality control, resource allocation, and capacity planning. Both distributions can be easily calculated using statistical tables or Excel functions.
