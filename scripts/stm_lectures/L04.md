# Lecture 4: Descriptive Statistics: Summarizing and Understanding Data

Overview
Descriptive statistics is the first step in making sense of raw data by providing statistical measurements that describe and summarize data. After collecting data, it is essential to transform it into useful, actionable information rather than relying on raw observations.
Summarizing Categorical Data
Frequency Distribution
A tabular summary that displays the number of observations in each non-overlapping category Categories must be mutually exclusive—a single observation cannot belong to multiple categories simultaneously Example: Hotel quality ratings (poor, below average, average, above average, excellent) where each guest provides exactly one rating
Relative Frequency and Percentage Frequency
- Relative frequency shows the proportion of observations in each category (calculated by dividing category frequency by total observations)
- Percentage frequency converts relative frequency to percentage form
- Sum of all relative frequencies equals 1.0; sum of all percentage frequencies equals 100%
- Provides insight into the distribution relative to the total sample size
Bar Charts
- Visual representation using vertical bars with fixed widths for each category
- Height represents frequency, relative frequency, or percentage frequency
- Effective for displaying qualitative data with minimal cognitive load
- Allows quick visual comparison across categories without reading exact values
Pie Charts
- Circular graph divided into sectors representing each category's proportion
- Each sector's angle is calculated as: relative frequency × 360 degrees
- Easy to understand proportions at a glance
- Best used for data with fewer than 5-6 categories to avoid clustering and confusion
Summarizing Quantitative Data
Frequency Distribution for Quantitative Data
- Data is divided into class intervals (ranges) rather than distinct categories
- Example: Parts cost grouped as 50-59, 60-69, 70-79, etc.
- Relative and percentage frequency calculations follow the same process as categorical data
- Allows compression of large datasets into manageable summaries while maintaining insights
Histograms
- Graphical representation similar to bar charts but for continuous, quantitative data
- Rectangles are drawn above each class interval with heights representing frequency, relative frequency, or percentage frequency
- Adjacent classes have no natural separation because data is continuous
- Provides visual representation of data distribution and patterns
Data Distribution Patterns
- Symmetric Distribution: Left tail mirrors the right tail; commonly seen in natural phenomena like human heights
- Left-Skewed Distribution: Longer tail on the left side; typically observed in exam scores where most students cluster in higher ranges with few lower scores
- Right-Skewed Distribution: Longer tail on the right side; commonly seen in housing prices with more variety in expensive properties than affordable options
Cumulative Frequency Distribution
- Adds up all previous class frequencies to show cumulative totals
- Demonstrates how frequency accumulates across class intervals
- Example: If frequency for class 50-59 is 2 and class 60-69 is 13, cumulative frequency at 69 is 15 (2+13)
- The last class always has cumulative frequency equal to the total number of observations
- Cumulative percentage frequency always reaches 100% at the final class
Analyzing Relationships Between Two Variables
Cross Tabulation
- Summarizes data for two variables simultaneously to identify relationships
- Can combine any data types: categorical-categorical, categorical-quantitative, or quantitative- quantitative
- Displays frequencies in rows and columns showing how variables interact
- Enables analysis of whether variables move together, move in opposite directions, or are independent
Row and Column Percentages
Row Percentages: Sum values across rows and divide by row total to understand distribution within each row category Column Percentages: Sum values down columns and divide by column total to understand distribution within each column category Critical to maintain consistency—if summing across rows, interpret percentages row-wise; if summing down columns, interpret column-wise Mismatching direction of calculation and interpretation leads to incorrect conclusions
Simpson's Paradox
A phenomenon where conclusions drawn from aggregate data may completely reverse when data is disaggregated into subgroups Occurs when cross-tabulation relationships appear different at aggregate versus detailed levels Requires careful attention to whether data is being analyzed at summary or detailed level Important consideration when drawing conclusions from cross-tabulated data to avoid misleading interpretations.
