# Lecture 18: Overview of Probability Distributions and Managerial Applications

This lecture covers the application of probability distributions (both discrete and continuous) in solving real-world managerial decision-making problems, with a focus on the Poisson distribution and normal distribution.
Main Topics Covered
1. Poisson Distribution Application: Automobile Dealership Staffing
Problem Context:
- Mr. Harriet McNeill owns an automobile dealership and wants to determine optimal staffing levels for Saturday mornings (busiest time)
- Average customer arrivals: 6.8 customers per hour
- Service time: Each salesperson spends approximately 1 hour per customer
- Business goal: Maintain 2+ customers on the lot beyond number of salespeople to create impression of high demand without losing frustrated customers
Key Concepts:
- Poisson distribution models the number of arrivals over a specified time interval
- Parameters required: Mean (λ) = 6.8 customers/hour
- The distribution assumes arrivals occur randomly at a constant rate
Problem Solving Approach:
Part 1: With 5 salespeople, calculate probability that customer arrivals exceed salespeople by more than 2
- Formula: P(X > 7) = 1 - P(X ≤ 7)
- Result: Approximately 37.2%
Part 2: Determine minimum salespeople needed so probability of exceeding by more than 2 stays ≤ 10%
- Required: P(X ≤ 9) ≥ 0.9
- Solution: 8 salespeople needed
- This yields probability of 8.5% (less than 10% threshold)
Important Distinction:
- Mass Function (PMF): Calculates probability at an exact point (e.g., exactly 7 customers)
  - Use when question contains word "exactly"
  - Example: P(X = 7)
- Cumulative Distribution Function (CDF): Calculates probability up to a point (e.g., 7 or fewer customers)
  - Use when question implies range or uses terms like "at least," "more than," "until," "till"
  - Example: P(X ≤ 7)
Excel Implementation:
- Function: =POISSON.DIST(x, mean, cumulative)
- x: number of arrivals
- mean: 6.8
- cumulative: FALSE for mass function, TRUE for cumulative distribution
2. Normal Distribution Applications
Characteristics of Normal Distribution:
- Continuous probability distribution (unlike Poisson's discrete nature)
- Defined by two parameters: Mean (μ) and Standard Deviation (σ)
- Bell-shaped, symmetric curve
- Represents most natural phenomena (income distribution, grades, heights, etc.)
Why Cumulative Functions Only:
- In continuous distributions, probability at a single exact point is virtually zero
- Impossible to calculate mass function for continuous data
- Only cumulative probabilities are meaningful and calculable
Case Study: MBA Graduate Starting Salaries
- Mean (μ) = $40,000
- Standard Deviation (σ) = $5,000
Example Problems:
- Probability of salary ≥ $30,000:
  - Calculate: P(X < 30,000), then find 1 - P(X < 30,000)
  - Result: 97.7%
- Probability of salary ≥ $47,500:
  - Apply same process
  - Uses: =NORM.DIST(47500, 40000, 5000, TRUE)
- Probability of salary between $34,000 and $46,000:
  - Method: P(X < 46,000) - P(X < 34,000)
  - Calculation steps:
  - ▪ Z₁ = (34,000 - 40,000) / 5,000 = -1.2
  - ▪ Z₂ = (46,000 - 40,000) / 5,000 = +1.2
  - Result: Approximately 76.9%
Standardization Using Z-Score:
- Formula: Z = (X - μ) / σ
- Purpose: Converts any normal distribution to standard normal (mean = 0, SD = 1)
Benefits:
- Makes distributions comparable across different scales
- Simplifies interpretation (Z-score shows how many standard deviations away from mean)
- Example: Z = -1.2 means 1.2 standard deviations left of mean
Excel Functions:
- =NORM.DIST(x, mean, standard_deviation, cumulative) - For any normal distribution
- =NORM.S.DIST(z, cumulative) - For standard normal distribution
- Recommendation: Use NORM.DIST to maintain awareness of standardization process
3. Language and Interpretation Guidelines
Critical for Problem Solving:
Term in Question Distribution Type Interpretation
"Exactly" Mass Function (Discrete) P(X = specific value)
"At least," "More than," "Till," "Until," "Between" Cumulative Function P(X ≤ value) or range probability Example Application:
- "Probability that exactly 10 customers arrive" → Use mass function
- "Probability that at least 10 customers arrive" → Use cumulative function
4. Real-World Application Principles
Data Collection:
- Historical data used to establish means and patterns
- Owner's experience validates statistical estimates
- Observation over multiple weeks helps identify busiest periods
Managerial Decision-Making:
- Statistics provides framework for optimal resource allocation
- Balances operational costs (employee salaries, benefits) with customer satisfaction
- Acknowledges that statistical estimates are approximations (never perfectly accurate every time)
- Creates competitive strategy (e.g., deliberate stock-outs to create perceived premium value)
5. Practical Considerations
Data Source Importance:
- Decisions based on archival/historical data
- Pattern recognition (e.g., identifying busiest hours)
- Average calculations provide decision-making foundation
Excel as Essential Tool:
- Visualization capabilities aid understanding
- Automation handles complex probability calculations
- Cumulative probability charts help identify thresholds visually
- Prevents manual calculation errors over infinite ranges
Limitations of Statistical Approach:
- Provides near estimates, not perfect predictions
- Subject to historical data quality
- Must account for unusual circumstances or market changes
- Serves as decision-support tool, not absolute answer
