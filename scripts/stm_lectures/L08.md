# Lecture 8: Overview of Statistics for Business and Economics: Descriptive Data Analysis and Customer Profiling

Key Concepts from Chapters 1-2: Frequency Distributions and Data
Visualization
Frequency Distribution
Definition: A tabular representation showing how data is distributed across different categories Components:
- Frequency: Count of observations in each category
- Example: Hotel ratings with frequencies (Poor: 2, Below Average: 3, Average: 5, Above Average: 9, Excellent: 1)
- Total sample size: 20 observations (important to note this represents a sample, not the entire population)
Relative and Percentage Frequency
Relative Frequency: Frequency divided by total number of observations Percentage Frequency: Relative frequency multiplied by 100 for easier communication and interpretation Advantage: Decimals are difficult to interpret; percentages provide better clarity for decision-making
Graphical Representations
Bar Charts: Effective for visual comparison across categories; easier to identify differences Pie Charts: Shows proportion of 360 degrees allocated to each category based on relative frequency Purpose: Provides quick visual interpretation and supports better business understanding
Grouped Data and Class Intervals
Structure: Data organized into mutually exclusive intervals (e.g., 50-59, 60-69, 100-109) Advantage: Prevents overlapping and allows clear categorization Application: Used when dealing with large datasets requiring organization
Histogram
Purpose: Visual representation of continuous or discontinuous distributions Shapes and Interpretations:
- Left-Skewed: Longer tail on left side; common in exam scores (fewer high scores, more low scores)
- Symmetric: Mirror image on both sides; typical for height distribution (equal people shorter and taller than average)
- Right-Skewed: Longer tail on right side; common in housing prices (few cheap homes, many expensive ones)
Cumulative Distribution
Concept: Progressive addition of frequencies from previous categories Example: Parts costing less than 69 includes both 50-59 and 60-69 categories Use: Understanding cumulative proportions rather than individual frequencies
Case Study: Pelican Stores - Data Analysis Application
Business Context
Organization: Division of national clothing chain operating across the country Objective: Evaluate effectiveness of promotional campaign using discount coupons Sample Size: 100 customer transactions during promotion period Assumption: Sales from promotional coupon customers represent incremental revenue not otherwise made
Data Collected
- Customer type (Regular vs. Promotional)
- Number of items purchased
- Net sales amount (dollar value)
- Gender
- Marital status
- Payment method
- Age
Manager's Analytical Goals
- Understand customer profile and demographics
- Determine if promotional strategy is effective
- Identify patterns in customer behavior
- Optimize future marketing strategies
Excel Techniques for Frequency Analysis
COUNTIF Formula
- Purpose: Count occurrences of specific categories in a dataset
- Syntax: =COUNTIF(range, criteria)
- Components:
  - Range: Column containing data to be counted
  - Criteria: Specific value to count
- Application: Use absolute references ($) for criteria cells to prevent changes when copying formulas
Pivot Tables
- Function: Summarize categorical and quantitative data automatically
- Steps:
- 1. Select data range
- 2. Insert → Pivot Table
- 3. Drag variables to appropriate fields (Rows, Columns, Values)
- 4. Analyze aggregated data
- Advantages: Handles missing data better; provides multiple view options
Key Findings from Pelican Stores Data
Promotional Effectiveness: 70% of customers were promotional (70 out of 100), indicating strong coupon response Purchase Behavior:
- Promotional customers purchased 266 total items (~4 items per customer average)
- Regular customers purchased 56 total items (~2 items per customer average)
- Promotional customers spend approximately double per transaction
Payment Methods: Proprietary card dominant (70 transactions), followed by Visa (10), MasterCard (14), Discover (3), American Express (2)
Descriptive Statistics: Measures of Central Tendency
Mean (Average)
Formula: Sum of all values ÷ Number of observations
Excel Function: =AVERAGE(range)
Advantage: Uses all data points
Limitation: Affected by extreme values (outliers)
Median
Definition: Middle value when data is arranged in order
Excel Function: =MEDIAN(range)
Advantage: Not affected by extreme values; more robust for skewed distributions Application: Preferred when outliers are present
Mode
Definition: Most frequently occurring value in dataset
Excel Function: =MODE(range)
Application: Only measure available for categorical variables and frequency data Note: Some datasets may have no mode or multiple modes
Highest and Lowest Values
- Maximum: =MAX(range) - Identifies largest value
- Minimum: =MIN(range) - Identifies smallest value
- Purpose: Establishes data range and identifies outliers
Central Tendency Applications and Selection Criteria
When to Use Mean
- Symmetric distributions without extreme outliers
- When all data points should be considered equally
- Financial calculations and cumulative analyses
When to Use Median
- Skewed distributions with potential outliers
- Income and housing price data
- When extreme values might distort analysis
When to Use Mode
- Categorical data exclusively
- Identifying most common category
- When frequency of occurrence is meaningful
Weighted Mean
Purpose: When different observations have different importance/weight Example: Course grade calculation where midterm, final exam, and VIVA have different weightages Application: Composite index calculations
Geometric Mean
Purpose: Average rate of change over time periods
Application: Calculating average returns on investments, compound growth rates Characteristic: Used for exponential or multiplicative data
Relationship Analysis: Two Quantitative Variables
Scatter Plots
Purpose: Visualize relationship between two continuous variables
Axis Configuration:
- X-axis (Horizontal): Independent variable
- Y-axis (Vertical): Dependent variable
- Example from Case: Age vs. Sales, Age vs. Number of Items Purchased
Pattern Interpretation
- Positive Relationship: As X increases, Y increases (upward trend)
- Negative Relationship: As X increases, Y decreases (downward trend)
- No Relationship: Data points scattered randomly with no apparent pattern
- Trend Line: Shows general direction and strength of relationship
Example Findings
- Positive relationship observed between customer age and per-item sales value
- Positive relationship between age and number of items purchased
- Suggests older customers tend to buy more items and spend more per item
Derived Metrics and Calculations
Per-Item Sales Value
Formula: Net Sales ÷ Number of Items
Calculation in Excel: =SalesColumn/ItemsColumn
Purpose: Normalizes spending across different purchase quantities for fair comparison Application: Identifies high-value customers independent of quantity purchased
Formula Copying Techniques
Absolute References: Use $ to lock cell references (e.g., $A$1) when copying Relative References: Allow cell references to change automatically during copy operations Double-Click Method: Automatically copies formula down to last available data row
