# Lecture 5: Graphical Displays for Summarizing Two Variables

Graphs provide a more effective way to understand data relationships compared to tables, as they require less cognitive effort to interpret. Two primary graphical techniques for exploring variable relationships are scatter diagrams and trend lines.
Scatter Diagrams
- Definition: A graphical representation of two quantitative variables plotted as points on a coordinate system
- Structure: One variable displayed on the horizontal axis (x-axis), the other on the vertical axis (y-axis)
- Interpretation: Each point represents an observation; the pattern of points reveals the relationship between variables
- Example: Age versus weight data shows that weight generally increases with age until approximately age 30, after which it stabilizes
Trend Lines and Relationship Types
Trend Line: A line drawn through scatter plot data to represent the general pattern or direction Positive Relationship:
- Both variables increase together
- Slope of the equation y = mx + c is positive
- Example: Number of interceptions versus points scored in football
Negative Relationship:
- As x increases, y decreases
- Slope is negative
- Example: Price of goods versus quantity consumed (demand curve)
No Apparent Relationship:
- Slope is zero; y remains constant regardless of x value
- No discernible pattern between variables
Side-by-Side Bar Charts
Purpose: Graphical display showing multiple bar charts simultaneously for comparing categorical data Structure: Each cluster of bars represents one category; individual bars within clusters represent different values of a second variable Advantage: Compresses complicated tabular data into easily readable visual format
Stacked Bar Charts
Purpose: Display relative proportions of categories within total frequencies Structure: Total frequency shown as full bar height, divided into colored segments representing different categories Benefit: When percentage frequencies are displayed, all bars have equal height (100%), making proportional comparisons easier Application: Useful for understanding distribution patterns, such as comparing cheaper versus costly homes
Overview of Data Summarization and Numerical Measures
The chapter covers two main types of data that require different summarization approaches: categorical and quantitative data. Understanding numerical measures is essential for analyzing populations and samples.
Data Types and Summarization Methods
Categorical/Qualitative Data:
- Tabular displays: Frequency distributions, relative frequency distributions, percentage frequency distributions, cross-tabulations
- Graphical displays: Bar charts, pie charts, side-by-side bar charts, stacked bar charts
Quantitative Data:
- Tabular displays: Frequency distributions, relative frequency distributions, cumulative frequency distributions, percentage frequency distributions
- Graphical displays: Histograms, scatter plots
- Outdated options: Dot plots, stem-and-leaf displays
Types of Statistics and Parameters
Sample Statistics: Numerical measures computed from a sample (subset of data) Example: Testing whether rice is cooked by examining a few grains instead of the entire batch Population Parameters: Measures computed from all elements in a complete dataset Example: Calculating class average using all students' scores Point Estimator: Sample statistic used to infer the corresponding population parameter Example: Average income of 50 surveyed individuals representing income for entire district
Measures of Central Location (Measures of Location)
Measures of location describe where the center or central tendency of data is positioned. Different measures are applicable depending on data characteristics and distribution patterns.
Mean (Average)
Definition: The sum of all data values divided by the number of values Formula:
x̄ = Σxi / n
Where Σ (sigma) represents summation, xi are individual values, and n is the count of observations Characteristics:
- Most common and intuitive measure
- Easy to calculate and interpret
- Affected by extreme values
- Useful when data is relatively symmetrical
Applications:
- Sports statistics (batting averages, strike rates)
- Monthly rental averages for apartment listings
Median
Definition: The middle value when data items are arranged in ascending order Calculation:
- Odd number of observations: The middle value is the median
- Even number of observations: Average of the two middle values
Advantages:
- Not affected by extreme values
- Preferred when data contains outliers
- More appropriate for skewed distributions
Applications:
- Placement data statistics (mitigates effect of extremely high or low salary offers)
- Property values and income data
- Annual rental markets with extreme values
Example: In apartment rental data, median of 575 versus mean of 590.8 shows median's stability against extreme values
Mode
Definition: The value that occurs with the greatest frequency in a dataset Variations:
- Unimodal: One mode exists
- Bimodal: Two modes exist
- Multimodal: More than two modes exist
Applications: Useful for identifying the most common or frequently occurring value in categorical or discrete data
Weighted Mean
Definition: Average calculated when observations have different relative importance or weights Formula:
x̄w = (Σ wi × xi) / Σ wi
Where wi represents the weight and xi represents the value
Applications:
- Calculating average wage per hour when workers have different hourly rates and hours worked
- Grade point average calculations where different courses have different credit hours
- Scenarios where importance varies by observation
Example: Home builder calculating average wage, considering both hourly rate and total hours worked per employee type
Geometric Mean
Definition: The nth root of the product of n values
Formula:
Geometric Mean = (x₁ × x₂ × x₃ × ... × xₙ)^(1/n)
Use Cases:
- Calculating mean rate of change over successive periods
- Preferred when dealing with multiplicative factors rather than additive factors
- Prevents misleading results when using arithmetic mean
Applications:
- Financial returns analysis over multiple periods
- Population growth rates
- Crop yield measurements
- Pollution level tracking
- Biological culture development (bacteria multiplication)
Key Principle: Applied when each observation depends on the previous observation, involving multiplication rather than addition
Percentiles
Definition: A value such that at least p percent of items take on this value or less Interpretation:
- 80th percentile: At least 80% of values are at or below this point; 20% are above
- 99th percentile: Only 1% of values exceed this point
Calculation Formula:
Location = (p/100) × (n + 1)
Where p is the percentile and n is the number of observations
Applications:
- College and university admission test scores
- Standardized test reporting (SAT, CAT, JEE)
- Comparing individual performance against larger populations
Example: In 70 apartment rentals, 80th percentile location = (80/100) × 71 = 56.8, indicating the 80th percentile rent is between the 56th and 57th values when sorted
Quartiles
Definition: Division of data into four equal parts using percentiles Types:
- First Quartile (Q1): 25th percentile
- Second Quartile (Q2): 50th percentile (median)
- Third Quartile (Q3): 75th percentile
Relationship to Median:
Second quartile equals the median because it represents the point where 50% of data falls below and 50% falls above Importance: Quartiles provide information about data spread and are foundational for box plot construction and five-number summaries.
