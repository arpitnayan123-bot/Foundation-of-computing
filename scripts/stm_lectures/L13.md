Discrete Probability Distributions
Definition and Characteristics
- Discrete distributions involve random variables that take fixed, non-continuous values
- Examples: rolling a dice (values 1-6), coin tosses (heads/tails), number of TV units sold
- Cannot assume values between defined points (e.g., cannot get 1.5 when rolling a dice)
- Can have finite or infinite sequences of values
Why Convert Observations to Mathematical Formulas
When dealing with probability data:
- Traditional Method: Calculate probability as favorable outcomes ÷ total outcomes
- Mathematical Formula Approach: Converts observed data into functions, making calculations easier and eliminating the need to observe all scenarios
- Key Advantage: Allows managers to estimate probabilities without waiting for complete datasets or endless observations
- Practical Benefit: Enables quick calculations using tools like Excel without requiring all historical data
Probability Distribution Example: TV Sales
Observed Data (200 days):
- 0 units sold: 80 days
- 1 unit sold: 50 days
- 2 units sold: 40 days
- 3 units sold: 10 days
- 4 units sold: 20 days
Conversion Process:
- Define random variable X (number of units sold)
- Calculate probability f(x) for each value
- Use formula: f(x) = (Number of favorable days) ÷ (Total days)
Expected Value (Mean)
Concept and Calculation
- Definition: Central location measure of a probability distribution; represents the mean value
- Formula: E(X) = Σ(X × f(x)) where X is the random variable and f(x) is its probability
- Calculation Method: Multiply each value by its probability, then sum all results
Practical Application
- Helps managers estimate future demand
- Enables inventory planning decisions
- Guides workforce hiring/firing decisions
- Supports business forecasting for upcoming periods
Example Outcome
When the TV distribution changes (adding 80 days of 10 units sold), expected value increases from 1.2 to 5.2 units per day This dramatic change illustrates how distribution modifications significantly impact business decisions
Variance and Standard Deviation
Need for Variance Measurement
- Mean Alone is Insufficient: Knowing only average demand can lead to inadequate inventory decisions
- Problem: If average demand is 3 units but you stock only 3 units, shortages occur on days with higher demand (e.g., 4 units needed)
- Solution: Measure variability/fluctuation in demand using variance
Variance Calculation
- Formula: Variance = Σ[(X - μ)² × f(x)]
- Why Squaring: Prevents negative and positive deviations from canceling each other out
- Key Point: Simple addition of deviations fails because overstock days offset understock days, masking actual variability
Standard Deviation
- Definition: Square root of variance
- Purpose: Provides interpretable measure of spread (same units as original data)
- Interpretation vs. Calculation:
  - Variance is useful for mathematical calculations
  - Standard deviation is better for practical interpretation and decision-making
Bivariate Analysis
Covariance and Correlation
- Used when two variables potentially move together or against each other
- Examples: Gold and silver prices, stock market performance of related companies
- Covariance: Calculative tool showing relationship direction
- Correlation: Interpretative measure providing clearer relationship insights
Common Discrete Distributions
Types Covered
- Binomial Distribution: Identical independent trials with two outcomes
- Poisson Distribution: Events occurring in fixed intervals
- Hypergeometric Distribution: (Not emphasized at this level)
- Uniform Distribution: Equally likely outcomes
Binomial Distribution
Conditions for Use
- Identical trials
- Only two possible outcomes per trial (success/failure)
- Constant probability of success in each trial
- Independent trials (previous outcomes don't affect subsequent ones)
Applications
- Coin tosses (independent events)
- Product quality testing (pass/fail scenarios)
- Success/failure scenarios with fixed probability
Excel Function
BINOM.DIST() with parameters: number of successes, number of trials, probability of success, cumulative (TRUE/FALSE)
Poisson Distribution
Characteristics
- Key Property: Probability of occurrence is same for any two equal-length intervals
- Formula: f(x) = (μ^x × e^(-μ)) ÷ x!
Parameters:
- x = number of occurrences in interval
- μ = mean occurrences in interval
- e = exponential constant (standard value)
Applications
- Queue management in banks, airports, railways
- Customer arrival modeling
- Event occurrence in fixed time intervals
Importance of Scientific Formulas
- Historical discovery after centuries of observation and trial-and-error
- Eliminates need to continuously observe and re-pattern data
- Provides consistent estimation across similar phenomena
Practical Implementation in Excel
Step-by-Step Process
- Create columns for: X (random variable), Number of Days, f(x) (probability)
- Calculate f(x) = Days ÷ Total Days for each value
- Verify: Sum of all f(x) values must equal 1
- Calculate X × f(x) for each row
- Sum X × f(x) to get expected value
- For variance: Calculate (X - Mean)², then multiply by f(x)
- Sum variance column and take square root for standard deviation
Key Takeaways
- Observation to Formula: Real-world data is converted to probability distributions using mathematical formulas
- Expected Value: Guides managers in planning inventory, workforce, and resource allocation
- Variability Matters: Standard deviation reveals actual demand fluctuations, enabling better risk management
- Distribution Types: Different scenarios require different distributions (binomial vs. Poisson)
- Tool Mastery: Using Excel formulas efficiently replaces manual calculations and reduces observation requirements
- Continuous Learning: Understanding both theoretical concepts and practical applications is essential for data-driven decision-making
