# Lecture 29: Understanding Hypothesis Testing: Type I and Type II Errors

Overview
This lecture discusses the fundamental concepts of hypothesis testing, focusing on Type I and Type II errors, their consequences, and how to control them in practical scenarios. The lecture emphasizes why researchers need to understand the trade-off between these two types of errors and how to design experiments based on the cost of errors.
Key Concepts
Type I and Type II Errors
- Type I Error (False Positive): Rejecting the null hypothesis (H₀) when it is actually true. This represents a false claim of discovery.
- Type II Error (False Negative): Failing to reject the null hypothesis when it is actually false. This represents a missed discovery.
- Not all errors are equally dangerous; the severity depends on the context and consequences of each type of error.
Why Errors Occur
- Errors are inevitable because researchers work with samples rather than entire populations
- Sampling limitations and potential biases introduce uncertainty into conclusions
- If the entire population were examined, there would be no chance for error
Why We Focus on Controlling Type I Error
- Level of Significance (α): The probability of making a Type I error, chosen by the researcher before conducting the experiment
- Common choices for α are 0.05 (95% confidence) and 0.01 (99% confidence)
- Type I error is controllable because the researcher directly selects the significance level
- Most literature emphasizes controlling Type I error because it represents the risk we knowingly accept
The Trade-off Between Type I and Type II Errors
The Inverse Relationship
- Decreasing Type I error increases Type II error, and vice versa
- You cannot simultaneously minimize both errors without increasing sample size
- The relationship is analogous to being strict versus lenient with admission criteria—being strict filters out late arrivals but also excludes genuine students with legitimate reasons
Classroom Analogy
- Strict professor (Low Type I, High Type II): Does not allow late students, filtering habitual latecomers but also excluding sincere students with genuine reasons
- Lenient professor (High Type I, Low Type II): Allows students until 9:10 AM, admitting all genuine students but also enabling habitually late students
Setting the Appropriate Alpha Level
Factors to Consider
- Cost of Type I Error: If rejecting H₀ when true is costly (e.g., approving a dangerous drug), use a smaller α
- Cost of Type II Error: If failing to reject H₀ when false is costly (e.g., missing an improvement), tolerate a larger α
- Who bears the cost: The party bearing the financial, health, or safety consequences should inform the choice of α
Decision-Making Framework
- When Type I error is more costly (e.g., FDA drug approval), use smaller α (0.01) to be very strict
- When Type I error is less costly (e.g., marketing claims), use larger α (0.05) to be more lenient
- Sample size can reduce both errors—larger samples lead to smaller sampling error
Accepting vs. Not Rejecting H₀
Terminology Distinction
- Accept H₀: Concludes that H₀ is true (implies more confidence than is justified)
- Fail to Reject H₀ or Do Not Reject H₀: Means insufficient evidence exists to conclude that H₀ is false (more statistically appropriate)
In rigorous research, saying "we do not reject H₀" is preferred because it acknowledges the risk of Type II error
Why This Matters
- Accepting H₀ suggests certainty about Type II error, which is difficult to calculate
- Not rejecting H₀ safeguards against overconfident conclusions and acknowledges uncertainty
- In practice, researchers often call for additional evidence or larger samples rather than accepting H₀
Practical Applications
Drug Approval (FDA Example)
- Type I Error: Approving a drug that is not safe or effective (rejecting H₀ when true)
- Type II Error: Rejecting a safe and effective drug (failing to reject H₀ when false)
- Consequences: Type I error is more dangerous because unsafe drugs harm public health and damage reputation
- Solution: Use very low α (0.01) to minimize approval of dangerous drugs
Fuel Injection System Example
- H₀: Mean pressure required ≤ 24 MPa
- H₁: Mean pressure required > 24 MPa (system improves)
- Type I Error: Claiming improvement when none exists (costly to company reputation)
- Type II Error: Rejecting an improvement that actually exists (costly to missed opportunity)
- Decision depends on comparing these costs
Electricity Bill Comparison
- Scenario: Testing if a Chicago neighborhood pays more than $104/month (Cincinnati average)
- H₀: μ ≤ 104
- H₁: μ > 104
- Type I Error: Concluding neighborhood pays more when it doesn't (perhaps picked high-consumption homes)
- Type II Error: Concluding neighborhoods have equal bills when Chicago actually pays more
- Consequence: No critical safety or financial issue; mainly tests a belief
Carpet Sales Incentive Plan
- Scenario: Testing if a new incentive increases average sales from $8,000/week
- H₀: μ ≤ 8,000
- H₁: μ > 8,000
- Type I Error: Claiming incentive works when it doesn't (wasting money on ineffective program)
- Type II Error: Rejecting a working incentive program (losing sales opportunity)
- Consequence: Type II error (lost sales) is more costly than Type I error (wasted incentive money)
- Solution: Use larger α to tolerate higher Type I error and lower Type II error
Key Takeaways
- Every hypothesis test has two possible errors; both cannot be eliminated entirely
- α (alpha) is the chosen, controllable risk of Type I error
- Type I error can always be calculated and determined; Type II error is harder to control
- Researchers should analyze who bears the cost and what the cost is before choosing α
- Instead of "accepting H₀," use "failing to reject H₀" or "do not reject H₀" to acknowledge uncertainty
- Design experiments with α in mind and consider increasing sample size to reduce both errors simultaneously
- Real-world decision-making requires context: drug safety demands stricter standards than marketing claims
Practice Applications
Quick Checks
- Fire Alarm Example: H₀ = no fire; alarm sounds but no fire = Type I Error; alarm doesn't sound when fire exists = Type II Error (more dangerous)
- Court Trial Example: H₀ = defendant is innocent; guilty defendant acquitted = Type II Error
- Email Spam Filter: H₀ = email is legitimate; legitimate email marked as spam = Type I Error
- Production Method: H₀ = method doesn't reduce costs; implement only if H₀ is rejected with strong evidence
