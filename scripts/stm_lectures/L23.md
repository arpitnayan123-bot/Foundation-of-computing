Sampling Methods for Estimating Population Mean
Random Sample Generation Process
- Use RAND BETWEEN function to generate random numbers between 1 and population size (e.g., 1 to 2,500)
- Copy the formula across all rows
- Important Step: Convert formulas to static values using Copy → Paste Special → Values Only (otherwise numbers will change dynamically)
- Sort data in ascending order using the filter function
- Select the first 50 values to form a random sample
- Calculate the average using formula AVERAGE(B2:B51) for sample size of 50
Why Random Sampling is Important
- Easier and more cost-effective than surveying entire population
- Sometimes infeasible to collect complete population data
- Every element in population must have equal chance of selection
- Each independent random sample will produce different mean values
Demonstration Results
- Population Size: 2,500 employees
- Actual Population Mean: 71,800 (salary)
- Sample Means Generated: Ranged from approximately 71,000 to 72,500
- Observation: Multiple random samples produced means very close to actual population mean
Standard Error and Sample Size Relationship
Formula
The standard error of the mean is calculated as: σ_x̄ = σ / √n
Where:
- σ = population standard deviation
- n = sample size
Key Finding
- When sample size increases from 50 to 100, standard error decreases
- Standard error is inversely proportional to the square root of sample size
- Larger samples produce more accurate estimates with less variability
Mathematical Verification
- For sample size 50: Standard error calculated from multiple samples
- For sample size 100: Standard error reduced by approximately √2 (square root of 2)
- This relationship was verified empirically through the exercise
Sampling Distribution of Proportions
Method to Calculate Proportion
- Used same random sampling technique with sample size of 100
- Filtered data to count specific categories (e.g., "No" for training program participation)
- Proportion = Count of specific category / Sample size
Proportion Estimates from Student Samples
- Multiple student samples yielded proportions: 0.36, 0.38, 0.39, 0.42, 0.45, 0.47
- Actual Population Proportion: 1,000 of 2,500 = 0.40
- Observation: Student estimates clustered closely around actual population proportion
Standard Error of Proportion Formula
σ_p̂ = √[p(1-p) / n]
Where:
- p = population proportion
- n = sample size
Central Limit Theorem Concept
- Regardless of population distribution shape, sampling distribution of means approaches normal distribution
- Requirement: Sample size of approximately 30 or more is generally sufficient
- Distribution shapes observed in exercise were slightly right-skewed but approached normality with adequate samples
- This concept is critical for creating confidence intervals and hypothesis testing
Important Distinctions
- Small n: Sample size used in each random draw
- Capital N: Total population size
- Number of Samples: How many times the sampling process is repeated (emphasized as crucial for good distribution)
- Sampling Distribution: Distribution of sample means (or proportions), NOT the distribution of individual data points in a sample
Sampling Without Replacement vs. With Replacement
- Correct Method: Generate new random numbers for each sample to ensure every population element has equal selection chance
- Incorrect Method: Systematically excluding already-selected elements, which introduces bias
- New random numbers each time maintain true randomness and avoid conditional probability issues
