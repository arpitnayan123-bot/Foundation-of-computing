# Lecture 30: Understanding One-Tailed Hypothesis Testing with P-Value and Critical Value Approaches

Overview of Hypothesis Testing
This lecture builds on previous sessions about hypothesis formulation and error types. The session focuses on conducting one-tailed hypothesis testing using both the p-value approach and critical value approach. It is emphasized that statistical conclusions always carry some risk of error (Type 1 or Type 2), and these risks must be managed through proper methodology.
Key Concepts
P-Value Approach
- P-Value Definition: The probability that measures the support or lack of support provided by the sample for the null hypothesis (H₀)
- Decision Rule: Reject H₀ if p-value ≤ α (level of significance)
Interpretation of P-Values:
- p-value ≤ 0.01: Overwhelming evidence to conclude H_A is true
- p-value between 0.01 and 0.05: Strong evidence to conclude H_A is true
- p-value between 0.05 and 0.1: Weak evidence to conclude H_A is true
- p-value > 0.1: Insufficient evidence; do not reject H₀
Level of Significance (α)
- Represents the probability of making a Type 1 error
- Common values: 0.05 (95% confidence) or 0.01 (99% confidence)
- Chosen before conducting the test
Critical Value Approach
- Uses the standard normal probability distribution (Z-distribution)
- Critical Value: The boundary value that establishes the rejection region
- Lower-Tailed Test: Reject H₀ if Z < -Z_α
- Upper-Tailed Test: Reject H₀ if Z > Z_α
- The critical value approach and p-value approach yield the same conclusions
Test Statistics Formula
When population standard deviation (σ) is known:
Z = (x̄ - μ₀) / (σ/√n)
Where:
- x̄ = sample mean
- μ₀ = hypothesized population mean
- σ = population standard deviation
- n = sample size
Steps in Hypothesis Testing
- Develop null and alternate hypotheses based on the research question
- Specify the level of significance (α) - determine acceptable risk level
- Collect sample data and compute the test statistic value
- Calculate the p-value using the test statistic
- Make decision:
  - Compare p-value to α
  - Or compare test statistic to critical value
  - Reject H₀ if condition is met
Practical Example: Metro EMS Response Time
Scenario: Test whether Metro EMS meets its 12-minute response goal Given Information:
- Sample size: n = 40
- Sample mean: x̄ = 13.25 minutes
- Population standard deviation: σ = 3.2 minutes
- Level of significance: α = 0.05
Hypothesis:
- H₀: μ ≤ 12 (service goal is being met)
- H_A: μ > 12 (service goal is not being met)
Solution:
- Test statistic: Z = (13.25 - 12)/(3.2/√40) = 2.47
- P-value = 1 - 0.9932 = 0.0068
- Since 0.0068 < 0.05, reject H₀
- Conclusion: There is sufficient statistical evidence that Metro EMS is not meeting the 12-minute response goal
Important Clarifications
Relationship Between Different Significance Levels
- If H₀ is rejected at 5% significance level, it may or may not be rejected at 1% significance level
- The critical value for α = 0.01 is further to the right than for α = 0.05
- A test statistic can fall between these two critical values, making rejection dependent on the chosen α level
Visual Understanding
Using normal distribution curves helps clarify:
- Where the critical region lies
- Whether a test statistic falls in the rejection region
- The relationship between different significance levels
Key Takeaways
- P-value and critical value approaches are complementary methods for hypothesis testing
- The choice of α should be made before collecting data
- Sample size (n > 30) allows use of the normal distribution by the Central Limit Theorem
- Both approaches will yield consistent decisions about rejecting or failing to reject H₀
- Proper visualization of the distribution and critical regions prevents decision-making errors
